# 五段活用

{% hint style="info" %}
在阅读本章节前，请确保您可以熟练背诵五十音图。
{% endhint %}

首先，让我们知道，什么是五段活用（ごだんかつよう）。

我们规定。词尾分布在「ウ」段上的动词，都叫做五段活用动词。\
不过，其中以「る」结尾的动词，不一定是五段活用动词，分辨方法在下文会详细说到。

在某些教学机构，此类动词也被称为【一类动词】。

首先，整理一个变形表格。\
这个表格需要熟记。

### 表格备注：

* 表格中连用存在两部分，在本表格中，第一个连用是礼貌体连用，第二个连用是词义连用。
* カ行五段活用中的「ゆく」（行く、往く、逝く）是連用形イ音便形「ゆい」的古用法。现代口语用「いく」促音便形「いっ」来代用。&#x20;
* ナ行五段活用中的「死（し）ぬ」，在西日本方言或古风类文体中的終止形、连体形也用作「しぬる」。
* 关于「会う・笑う」等，中国教材上写为「ア行」的变形，正确应该属于「ワア行」。
* 任何动词的连体形单独使用，将作为一个名词。

## 如何看懂表格

我相信，新学习者，很可能看不懂这个表格。或者没有接受过正规日语学习的人，也有可能没有接触过这个表格。

在这里，将教会你如何看懂这类表格。因为下文会大量使用这种表格。

比方说，动词【刺す】为例。\
根据上面的变形规则，你可以整理出：

<table><thead><tr><th width="60">行</th><th width="79.20001220703125">基本形</th><th width="97.5999755859375">词干</th><th width="74.39996337890625" align="center">未然形</th><th width="84" align="center">连用形</th><th width="71.2000732421875" align="center">终止形</th><th width="72" align="center">连体形</th><th width="71.2000732421875" align="center">假定形</th><th width="83.9998779296875" align="center">命令形</th></tr></thead><tbody><tr><td>サ</td><td>刺す</td><td>刺（さ）</td><td align="center">さ</td><td align="center">し・し</td><td align="center">す</td><td align="center">す</td><td align="center">せ</td><td align="center">せ</td></tr></tbody></table>

「刺す」是它的基本形，也是它的终止形。

如果你想要表达否定，那么将要变成未然形，再接「ーない」\
即「刺さない」。\
你可以看到，这是 词干+屈折形+表意 这样的情况组成的一个词语。\
同理，你要表达连用，则是「刺します・刺して・刺した」。

如果您依然无法看懂这里的描述，那么我会在助动词及动词用法，加入最为简单的屈折用法演示。
