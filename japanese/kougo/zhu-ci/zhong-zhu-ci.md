description: 主要出现在句末，用于表达说话者对听话者的态度或语气。
---

# 终助词

接在句末，负责把说话人的态度带出来。疑问、求同、告知、感叹、禁止，都靠它落点；同一句话换个终助词，意思就换个方向。

| 终助词 |    功能    |    语气倾向   |
| :-: | :------: | :-------: |
|  か  | 疑问、自问、劝诱 |     中性    |
|  ね  | 确认、求同、缓和 |     柔和    |
|  わ  |  感叹、轻微主张 |    偏柔和    |
|  よ  | 告知、提醒、推动 |    中性偏强   |
|  ぞ  |   警告、决心  |   强，偏男性   |
|  な  | 感叹、禁止、促请 | 偏男性，随用法变化 |
|  の  | 亲近的疑问、确认 |     柔和    |
|  さ  |  轻描淡写的主张 |    偏男性    |
|  っけ |   回忆、确认  |     中性    |
|  かな | 自问、推测、愿望 |     柔和    |
|  もの |  理由、强烈否定 |   口语，偏柔和  |

***

### か

{% hint style="info" %}
读作「カ」；句末上扬表疑问，读得平或下沉则多为自问、确认
{% endhint %}

接在句末，把不确定的事交给对方，或说给自己听。

{% stepper %}
{% step %}
**疑问** - 提出不确定的事，等对方给个答案\
明日は休みです**か**。\
（明天放假吗？）\
（书面语里句末的「か」读平调；口语靠语调分疑问与确认）
{% endstep %}

{% step %}
**自问・推测** - 说给自己听，相当于中文的「是不是…呢」\
これでいいの**か**。\
（这样就行了吗。）\
何時に帰ろう**か**。\
（几点回去好呢。）
{% endstep %}

{% step %}
**劝诱・提议** - 与意志形搭配，把决定权递出去\
そろそろ行こう**か**。\
（差不多该走了吧。）\
お条でも飲もう**か**。\
（喝点茶什么的吧。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
这里只取句末的用法，与[系助词](xi-zhu-ci.md)页的「か」是同一个词\
接在句中表不确定的用法（雨が降る**か**どうか），放在系助词页
{% endhint %}

### ね

{% hint style="info" %}
读作「ネ」；拉长时写作「ねえ」，多半带点感慨，语气也更松
{% endhint %}

接在句末，把自己知道的事拿出来与对方对齐。

{% stepper %}
{% step %}
**确认・求同** - 请对方点头，相当于中文的「对吧」「是吧」\
今日は寒いです**ね**。\
（今天挺冷的呢。）\
（对方一般会答一句「そうですね」）

明日は休みでした**ね**。\
（明天是休假来着吧？）\
（心里已有判断，只等对方确认）
{% endstep %}

{% step %}
**共鸣・感叹** - 与自己的感受相呼应，不一定要对方回答\
本当に綺麗だ**ね**。\
（真漂亮啊。）\
冬の空は気持ちがいい**ねえ**。\
（冬天的天空真舒服啊。）
{% endstep %}

{% step %}
**缓和语气** - 接在请求、劝告后，把口气放软\
もう一度確認して**ね**。\
（再确认一次哦。）\
（比起「よ」「ぞ」，「ね」把自己放到对方那一侧）
{% endstep %}
{% endstepper %}

### わ

{% hint style="info" %}
读作「ワ」；语气柔和，女性语中常见，男性多用方言或粗犷的变体
{% endhint %}

接在句末，把感受或主张轻轻放上去。

{% stepper %}
{% step %}
**感叹** - 略带主张的感叹，多用于独白或随口一句\
知らない**わ**。\
（我不知道啊。）\
明日は忙しい**わ**。\
（明天可忙了。）
{% endstep %}

{% step %}
**轻微的主张・意志** - 表自己的决定，语气比「よ」软\
じゃ、先に帰る**わ**。\
（那我先回去了啊。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
关西腔里「わ」用得比共通语多，男女都常用，语感也硬一些\
そうや**わ**。（関西腔：是那样啊。）
{% endhint %}

### よ

{% hint style="info" %}
读作「ヨ」；把对方还不知道的信息推过去，语气比「ね」硬
{% endhint %}

接在句末，用于告知、提醒或推动对方。

{% stepper %}
{% step %}
**告知・提醒** - 对方没注意到的事，用「よ」推他一把\
危ない**よ**。\
（危险哦。）\
この店は日曜が休みだ**よ**。\
（这家店周日休息哦。）
{% endstep %}

{% step %}
**催促・劝诱** - 推动行为，语气略强\
そろそろ行く**よ**。\
（差不多该走了啊。）
{% endstep %}

{% step %}
**强调・断言** - 把判断钉在句末\
本当だ**よ**。\
（是真的。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
与「ね」的分界线在信息归属，「よ」说的是对方不知道的事，「ね」说的是双方都知道的事\
明日は休みだ**よ**。（你还不知道，告知）／明日は休みだ**ね**。（都知道，对齐）
{% endhint %}

### ぞ

{% hint style="info" %}
读作「ゾ」；男性语，语气强，常用来自言自语或半开玩笑的警告
{% endhint %}

接在句末，用于施压式的告知与自我宣言。

{% stepper %}
{% step %}
**警告・强烈告知** - 把压力给到对方\
食べ過ぎると太る**ぞ**。\
（吃太多会胖的哦。）\
もう遅い**ぞ**。\
（已经很晚了。）
{% endstep %}

{% step %}
**自言自语式的决心** - 说给自己听\
よし、やる**ぞ**。\
（好，干了。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
「ぜ」与「ぞ」功能相近，语气更轻、更随便，多见于男性口语\
遊びに行く**ぜ**。（去玩喽。）
{% endhint %}

### な

{% hint style="info" %}
读作「ナ」；同形不同用，感叹时拉长成「なあ」，禁止时接动词原形
{% endhint %}

接在句末，表感叹、禁止或促请。

{% stepper %}
{% step %}
**感叹・自语** - 拉长成「なあ」时更松\
綺麗だ**な**。\
（真漂亮啊。）\
明日は晴れるといい**なあ**。\
（明天放晴就好了。）
{% endstep %}

{% step %}
**禁止** - 接动词原形，语气强硬\
触る**な**。\
（别碰。）\
ここに入る**な**。\
（别进来。）\
（与「〜ないでください」对照，「な」不做缓冲）
{% endstep %}

{% step %}
**促请** - 接动词连用形，语气比命令柔和，多为男性或长辈口吻\
早くし**な**。\
（快点吧。）\
遠慮せず食べ**な**。\
（别客气，吃吧。）
{% endstep %}
{% endstepper %}

### の

{% hint style="info" %}
读作「ノ」；上扬表疑问，下降表确认或轻微断定，语气比「か」亲近
{% endhint %}

接在句末，用于亲近关系里的疑问与确认。

{% stepper %}
{% step %}
**疑问（上扬）** - 比「か」软，多用于家人、朋友之间\
どこへ行く**の**？\
（去哪儿呀？）\
食べない**の**？\
（不吃吗？）\
（正式场合或对上级仍用「か」；男性用「の」会显得亲近或随意）
{% endstep %}

{% step %}
**确认・轻微断定（下降）** - 把自己知道的事轻轻带出\
そうな**の**。\
（是这样啊。）\
明日は休みな**の**。\
（明天休息的。）
{% endstep %}
{% endstepper %}

### さ

{% hint style="info" %}
读作「サ」；男性口语里多，用来把话说得轻描淡写
{% endhint %}

接在句末，表轻描淡写的主张或放开的态度。

{% stepper %}
{% step %}
**轻描淡写的主张** - 不把话说满，带点无所谓\
まあ、いい**さ**。\
（算了，也行吧。）\
そのうち分かる**さ**。\
（迟早会明白的。）
{% endstep %}

{% step %}
**放手・自嘲** - 与「どうせ」类词语呼应，把结论轻轻丢开\
どうせ間に合わない**さ**。\
（反正也赶不上。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
「さ」也能插在句子中间，只起填气的作用，不改变句意\
それが**さ**、昨日の話なんだけど……（那个啊，就是昨天那事……）
{% endhint %}

### っけ

{% hint style="info" %}
读作「ッケ」，读作促音成节；用于回忆或确认记不清的事
{% endhint %}

接在句末，向对方确认自己模糊的记忆。

{% stepper %}
{% step %}
**回忆・确认** - 相当于中文的「是…来着？」\
明日は休みだ**っけ**？\
（明天是放假来着？）\
名前、何だ**っけ**。\
（名字叫什么来着。）
{% endstep %}

{% step %}
**想起来・自问** - 一个人自言自语，往往并不需要回答\
あれ、鍵閉めた**っけ**。\
（咦，锁门了来着吗。）
{% endstep %}
{% endstepper %}

### かな

{% hint style="info" %}
读作「カナ」；柔和的自问、推测或愿望，女性多用同义的「かしら」
{% endhint %}

接在句末，把不确定的判断或期待停在句末。

{% stepper %}
{% step %}
**自问・推测** - 不下断语，自己把话悬着\
これで大丈夫**かな**。\
（这样没问题吧。）\
明日は晴れる**かな**。\
（明天会晴吗。）
{% endstep %}

{% step %}
**愿望** - 与期待的事搭配，等于轻声许个愿\
早く帰れない**かな**。\
（能早点回去就好了。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
「かしら」与「かな」同义，语气更柔，女性语中常见\
明日は晴れる**かしら**。（明天会晴吗。）
{% endhint %}

### もの

{% hint style="info" %}
读作「モノ」；口语中常缩成「もん」，接在句末表理由或强烈否定
{% endhint %}

接在句末，表理由、辩解或把话钉死的否定。

{% stepper %}
{% step %}
**理由・辩解** - 带点撒娇口气，相当于中文的「因为嘛」\
だって忙しいんだ**もの**。\
（因为人家忙着嘛。）\
知らなかったんだ**もん**。\
（我又不知道嘛。）
{% endstep %}

{% step %}
**强烈否定（〜ものか）** - 用反问把结论钉死\
負ける**ものか**。\
（谁会输啊。）\
そんな話、信じる**ものか**。\
（那种话谁会信。）
{% endstep %}
{% endstepper %}
