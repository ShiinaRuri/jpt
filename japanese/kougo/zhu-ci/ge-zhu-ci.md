# 格助词

### が

一般地，添加在名词或类名词之后。

在大部分教科书中，它和「は」也被视为提示主格的助词。\
不过在语言学分析上，也有将「が」和「は」作为副助词（取り立て助詞）的用法。\
此时，如果是连接「を」「に」这种格助词的场合，不会出现「をが」「にが」这种形式，而是都记作「が」。\
不过如果是系助词「は」的场合，会出现「には」的形式，而不会出现「をは」。

### の

可以自由地添加在体言（名词）、用言（有变化形式的词）和助词后（「う」「よう」「まい」以外）。\
表示两个词或小句之间的支配关系。

<table data-card-size="large" data-view="cards"><thead><tr><th></th><th></th></tr></thead><tbody><tr><td>連用修飾語の動作や状態の主体を表す</td><td>属格(連体格)</td></tr><tr><td>兄<strong>の</strong>匂い</td><td>兄<strong>の</strong>着た服</td></tr><tr><td>表连用修饰语的动作或状态的主体</td><td>表属格</td></tr><tr><td>哥哥<strong>的</strong>味道</td><td>哥哥穿<strong>的</strong>衣服</td></tr></tbody></table>

### を

宾格的格助词。\
它必须和动词一起使用，添加在名词或类名词之后。

<table data-card-size="large" data-view="cards"><thead><tr><th></th><th></th><th></th></tr></thead><tbody><tr><td>動作の直接的な対象や知覚・思考活動の対象</td><td>移動時の経路を示す</td><td>移動の起点や経由点も示すが、この場合には到着点を想定していない場合となる。</td></tr><tr><td>本<strong>を読む</strong></td><td>橋<strong>を渡る</strong></td><td>家<strong>を出る</strong></td></tr><tr><td>动作上的直接对象或主观思考的对象</td><td>移动的路线指示</td><td>移动的起点或途径点指示，但不到达指示的地点。</td></tr><tr><td><strong>读</strong>书</td><td><strong>过</strong>桥</td><td><strong>离</strong>家</td></tr></tbody></table>

### に

与格（也叫给[^1]格）的格助词。\
它添加在名词、类名词、动词连用形和连用形之后。

<table data-card-size="large" data-view="cards"><thead><tr><th></th><th></th><th></th><th></th><th></th><th></th></tr></thead><tbody><tr><td>物体の存在する場所や移動の目標点および到達点</td><td>相手に視点を置いたときの相手の動作、対象に対する指向性が感じられるときの動作および状態の対象</td><td>主体から相手に対し動作や関係が一方的に及ぶ時の相手</td><td>比較、割合の基準を表す</td><td>そのものに、さらに何かを添える意を表す</td><td>状態の主体、変化の結果、生じたものであることを表す</td></tr><tr><td>庭に犬がいる<br>後に車が来る</td><td>海岸で人々にフライドポテトを口に入れる・<br>教室に勉強する</td><td>小鳥に撃つ<br>教室に破壊する</td><td>千人に一人の合格率</td><td>鬼に金棒<br>水に砂糖</td><td>氷が水になる<br>男の子を女の子になる</td></tr><tr><td>物体的存在场所、移动的方向或到达点</td><td>第三人称中，他人的动作、有对象的指向性动作及状态的对象</td><td>第一人称中，动作发起者的动作对象或与之关系时的对象</td><td>比较基数的标准</td><td>对象目标上的名词添加</td><td>状态的主体、变化的结果</td></tr><tr><td>后院里有犬<br>后方来车</td><td>在码头向人们整点薯条<br>在教室里学习</td><td>合格率0.1%</td><td>射击小鸟<br>破坏教室</td><td>如虎添翼<br>水中添糖</td><td>冰变成水<br>把男孩子变成女孩子</td></tr></tbody></table>

### へ

方向格、对格、到达格的格助词。\
对于现代文来说，使用范围很窄，并且只添加在名词后面。

{% hint style="success" %}
「へ」和「に」在表达移动方向上的意思几乎相同，可能存在混用。\
但相比「に」，它更多用于强调对象，而不偏向强调原因。
{% endhint %}

<table data-card-size="large" data-view="cards"><thead><tr><th></th><th></th></tr></thead><tbody><tr><td>移動の向きあるいは目標</td><td>到達点を表す</td></tr><tr><td>上へ投げる・北へ向かう・将来のあたしへ</td><td>買った品物を家へ運ぶ</td></tr><tr><td>移动面向的目标</td><td>表动作的移动目的地</td></tr><tr><td>向上投掷；向北出发；致未来的本可儿</td><td>把买来的货物向家搬运</td></tr></tbody></table>

### と

一般地，在现代文里，「と」最常用的意思就是表并列和引用。\
这里只列出现代文中「と」的用法。

<table data-card-size="large" data-column-title-hidden data-view="cards"><thead><tr><th></th><th></th><th></th><th></th></tr></thead><tbody><tr><td>共同の相手</td><td>作用の結果</td><td>引用</td><td>並立を示す</td></tr><tr><td>友人と食べる</td><td>作家となる</td><td>「今日は休もう」と言った</td><td>私と貴方と妹</td></tr><tr><td>共同动作的对手</td><td>作用的结果</td><td>表引用</td><td>表并列</td></tr><tr><td>和朋友一起吃</td><td>成为作家</td><td>我说：“今天休息吧”</td><td>我和你和（我的）妹妹</td></tr></tbody></table>

此外，「と」还可以表示状态，请看下方实例。

> さっさと片付ける。\
> ちゃんと覚えるよね！\
> 燦然と輝く星<br>
>
> 快速地收拾干净。\
> 给我好好地记住噢！\
> 璀璨地闪耀的星

通过实例可以知道，这是状语用法。

{% hint style="info" %}
因为这是文语（也就是古语）残留的用法，所以没有在篇章中写入。\
虽然可能不会在考试中遇到，但这种用法还是非常常用的，至少应该知道存在这种用法。
{% endhint %}

这种用法会在文语篇章详细说明。对于口语（现代日语），只需要记住基础用法。

### から

一个表示起点的助词，既可以是实际意义的起点，也可以是抽象意义的起点（字典解释：動作の主体が経由点としての性格を持つ場合の主体や物事の移動に視点を置いた場合の動作の起点である相手/移動の起点や経由点）。

<table data-card-size="large" data-view="cards"><thead><tr><th></th><th></th><th></th><th></th><th></th></tr></thead><tbody><tr><td>時・所を表す語に付いて，起点・経由点・出所などを示す</td><td>抽象的な起点・出所</td><td>資料・素材・原料に示す</td><td>原因・理由を示す</td><td>起算の初めを示す</td></tr><tr><td>八時から始まる・今日から作動する・東京から大阪に着いた</td><td>危険から遠ざかる・心から感謝する</td><td>水から酒を作る・爆弾は硝酸からできている</td><td>交通事故から遅刻した</td><td>一番安い鞄は五千円からだ</td></tr><tr><td>接在表示时间、场所的词语后，表示起点、途径点、出处</td><td>表抽象的起点、出处</td><td>表事物的原料或素材</td><td>表原因或理由</td><td>接在表示数量的词语后，表示接近那个数量（理解为...左右）</td></tr><tr><td>从八点开始；从今天工作；从东京出发到达大阪</td><td>远离危险；衷心感谢</td><td>用水酿的酒；用硝酸做成的炸弹</td><td>因为交通事故，所以迟到了</td><td>最便宜的袋子大约要5000元</td></tr></tbody></table>

### より

这是一个文语助词，现在只有两个常用意思。

<table data-card-size="large" data-view="cards"><thead><tr><th></th><th></th></tr></thead><tbody><tr><td>比較の基準に用いる</td><td>起点を表す用法も備えるが、現在は主に文章語となり、「から」と意味が重なっている</td></tr><tr><td>今年は去年より暑い・私より強い者</td><td>八時より始まる・九時より開会する・友達より手紙が来た</td></tr><tr><td>表比较的基准</td><td>表动作、作用的出发点的另一种用法（现在主要用在正式的文章上，「から」的郑重版本）</td></tr><tr><td>今年比去年更热；比我更强的人</td><td>在八点开始；在九点开会；朋友寄来的信件</td></tr></tbody></table>

{% hint style="info" %}
如果真要对比「より」和「から」对于表示出发点的区别，\
你可以理解为「から」表示的是一个时间和那个往后的时间段，而「より」表示刚好在那个时间点。
{% endhint %}
