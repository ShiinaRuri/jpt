# 副助词

副助词接在名词、代词、副词乃至整个句子之后，负责把范围收窄、把程度抬高、或者把某项举成极端例子。它不指定词语之间的语法关系，做的是往词上添意义，所以常与格助词叠用。

| 副助词 |     功能     |    语感   |
| :-: | :--------: | :-----: |
|  だけ |    限定（只）   |    中性   |
|  しか |  限定＋否定（只有） | 必须与否定呼应 |
| ばかり | 数量偏多、反复、刚刚 |  带主观评价  |
|  まで |  极端例示、到…为止 |    中性   |
|  ほど |    程度、比较   |   偏书面语  |
| くらい |   大致程度、约数  |    口语   |
|  のみ |    限定（只）   |   书面语   |
|  きり |  只有、自…以后没再 | 常接否定与过去 |
|  ずつ |   等量分配、渐进  |    中性   |
| なんか |    轻视、举例   |  口语，带感情 |
|  とか |    举例并列    |    口语   |
|  だの |    列举、唠叨   |  口语，带不满 |

***

### だけ

{% hint style="info" %}
读作「ダケ」，汉字写作「丈」；限定范围内的全部，语感中性
{% endhint %}

接在名词、数量词之后，把范围收到这一项上。

{% stepper %}
{% step %}
**限定** - 相当于中文的「只」「仅」\
水**だけ**飲んだ。\
（只喝了水。）\
三人**だけ**来た。\
（只来了三个人。）\
（同一件事落在否定侧时，用「しか」）
{% endstep %}

{% step %}
**最大限度** - 与可能形、愿望搭配，表"能到多少就到多少"\
できる**だけ**早く来てください。\
（请尽可能早点来。）\
好きな**だけ**食べなさい。\
（爱吃多少吃多少。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
「だけ」是中性陈述，「ばかり」带说话人的评价，嫌多或者嫌频繁\
酒**ばかり**飲んでいる。（老是喝酒，听着就烦）／酒**だけ**飲んだ。（只是喝了酒）
{% endhint %}

### しか

{% hint style="info" %}
读作「シカ」，必须与否定形式呼应，单用不成立
{% endhint %}

接在名词、数量词之后，把范围收到唯一一项。

{% stepper %}
{% step %}
**限定＋否定** - 相当于中文的「只有」\
千円**しか**ない。\
（只有一千日元。）\
（肯定侧的同一件事，说成 千円だけある）
{% endstep %}

{% step %}
**与格助词叠用** - 接在「に」「で」「と」之后带出限定\
ここで**しか**買えない。\
（只有这里能买到。）\
私に**しか**分からない。\
（只有我才懂。）
{% endstep %}

{% step %}
**〜しかない** - 表别无他法，相当于中文的「只好」\
待つ**しかない**。\
（只好等。）\
（与「〜ほかない」同义，语感更口语）
{% endstep %}
{% endstepper %}

### ばかり

{% hint style="info" %}
读作「バカリ」，汉字「許り」；口语里常听成「ばっかり」
{% endhint %}

接在各种词语之后，表数量偏多、反复，或者动作刚刚结束。

{% stepper %}
{% step %}
**量多・反复（带评价）** - 话说出来带点不满\
酒**ばかり**飲んでいる。\
（老是喝酒。）\
文句**ばかり**言う。\
（净抱怨。）
{% endstep %}

{% step %}
**〜てばかりいる** - 强调反复，语气更重\
遊んで**ばかりいる**。\
（老是玩。）\
（比单说「遊んでいる」多一层抱怨）
{% endstep %}

{% step %}
**刚刚（〜たばかり）** - 动作结束不久\
今帰ってきた**ばかり**だ。\
（刚回来。）\
（与「〜たところだ」相比，「ばかり」允许中间隔了些时间）
{% endstep %}
{% endstepper %}

### まで

{% hint style="info" %}
读作「マデ」；一副面孔当格助词，一副面孔当副助词
{% endhint %}

接在名词之后，表极端例示或者终点。

{% stepper %}
{% step %}
**极端例示（副助词）** - 相当于中文的「连…都」\
子供に**まで**笑われた。\
（连小孩都笑我。）\
そんなこと**まで**言うのか。\
（连那种话都说？）\
（举出极端例子，暗示其余更不必说）
{% endstep %}

{% step %}
**终点・期限（格助词）** - 表空间或时间的界限\
駅**まで**歩く。\
（走到车站。）\
五時**まで**待つ。\
（等到五点。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
判别的标准是句意落在"界限"还是"也得算上一份"\
五時**まで**待つ。（时间界限）／知らない人に**まで**聞かれた。（连陌生人都在打听）
{% endhint %}

### ほど

{% hint style="info" %}
读作「ホド」，汉字写作「程」；表程度，语感偏书面
{% endhint %}

接在名词、数量词或从句之后，把程度写出来。

{% stepper %}
{% step %}
**程度** - 相当于中文的「…的程度」\
死ぬ**ほど**疲れた。\
（累得要死。）\
涙が出る**ほど**嬉しかった。\
（高兴得眼泪都出来了。）
{% endstep %}

{% step %}
**比较（〜ほど〜ない）** - 与否定搭配，表"没有…那么…"\
今年は去年**ほど**寒くない。\
（今年没去年那么冷。）
{% endstep %}

{% step %}
**〜ば〜ほど** - 表"越…越…"\
練習すればする**ほど**上手になる。\
（越练越熟练。）
{% endstep %}
{% endstepper %}

### くらい（ぐらい）

{% hint style="info" %}
读作「クライ／グライ」，汉字「位」；口语里比「ほど」更常用
{% endhint %}

接在数量词或句子之后，表大致程度或约数。

{% stepper %}
{% step %}
**约数・大致程度** - 相当于中文的「大约」「差不多」\
一時間**ぐらい**待った。\
（等了大约一小时。）\
（正式文章的约数用「約」，「くらい」偏口语）
{% endstep %}

{% step %}
**轻描淡写・最低限度** - 把程度往下压，带点不以为然\
それ**くらい**分かるよ。\
（那种程度我懂啦。）\
挨拶**ぐらい**しなさい。\
（至少打个招呼吧。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
极端例示时可以互相替代，语气有别，「くらい」更轻\
泣きたい**くらい**つらい。（轻）／泣きたい**ほど**つらい。（重，书面）
{% endhint %}

### のみ

{% hint style="info" %}
读作「ノミ」，书面语的限定，公文、通知里常见
{% endhint %}

接在名词之后，把范围收到唯一一项。

{% stepper %}
{% step %}
**限定** - 意思等于「だけ」，场合不同\
応募は一人**のみ**。\
（报名仅限一人。）\
（日常会话说「一人だけ」，正式文书用「のみ」）
{% endstep %}

{% step %}
**〜のみならず** - 表"不仅"，与「〜だけでなく」同义\
学生**のみならず**社会人も参加した。\
（不仅学生，社会人士也参加了。）
{% endstep %}
{% endstepper %}

### きり

{% hint style="info" %}
读作「キリ」，口语常写成「っきり」；多与否定、过去呼应
{% endhint %}

接在名词之后，表"只有"，或者"自那以后没再"。

{% stepper %}
{% step %}
**只有** - 与「だけ」相近，多一层"再没别的"\
二人**きり**で話した。\
（只有两个人聊了聊。）\
これ**っきり**だ。\
（就这一次，往后没了。）\
（「〜きり」后面常接否定，把范围钉死）
{% endstep %}

{% step %}
**自…以后（〜たきり〜ない）** - 表某动作发生后就没再出现\
出かけた**きり**帰ってこない。\
（出去就没再回来。）\
（过去的事配上否定，是「きり」的典型搭配）
{% endstep %}
{% endstepper %}

### ずつ

{% hint style="info" %}
读作「ズツ」，汉字「宛」；表等量分配，或者一部分一部分地推进
{% endhint %}

接在数量词之后，把量按份分出去。

{% stepper %}
{% step %}
**等量分配** - 每份的量相同\
一人に二枚**ずつ**配る。\
（每人发两张。）\
（必须与数量词搭配，单说「ずつ」不成立）
{% endstep %}

{% step %}
**渐进** - 每次一点，动作慢慢推进\
少し**ずつ**覚えていく。\
（一点点记住。）\
毎日三十分**ずつ**走る。\
（每天跑三十分钟。）
{% endstep %}
{% endstepper %}

### なんか（なんて）

{% hint style="info" %}
读作「ナンカ／ナンテ」，口语里的轻视、举例或意外，带说话人的感情
{% endhint %}

接在名词、句子之后，把语气压低或者带出情绪。

{% stepper %}
{% step %}
**轻视・自谦** - 把自己的位置往下放\
私**なんか**まだまだです。\
（我这种还差得远。）\
（也能表示对第三方的轻视，语气不客气）
{% endstep %}

{% step %}
**举例** - 相当于中文的「…什么的」\
映画**なんか**見に行こうか。\
（去看个电影什么的吧。）
{% endstep %}

{% step %}
**なんて：意外・轻视** - 接在引用或句末，常带惊讶\
彼が来る**なんて**聞いていない。\
（没听说他会来呀。）\
（「なんか」偏举例与轻视，「なんて」常接引用式的感叹）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
「なんか」「なんて」都属口语，正式文书里换成「など」\
映画**など**見に行こうか。（书面一点的说法）
{% endhint %}

### とか

{% hint style="info" %}
读作「トカ」，口语的举例并列，可与「や」对照
{% endhint %}

接在名词之后，举出例子，暗示还有别的。

{% stepper %}
{% step %}
**举例并列** - 比「や」口语，接续也更自由\
りんご**とか**バナナを買った。\
（买了苹果、香蕉之类的。）\
週末は掃除**とか**洗濯をする。\
（周末做做打扫、洗衣服之类的事。）
{% endstep %}

{% step %}
**口语的传闻** - 挂在句末，表"听说"\
明日は雨だ**とか**。\
（说是明天有雨。）\
（正式场合用「〜だそうだ」）
{% endstep %}
{% endstepper %}

### だの

{% hint style="info" %}
读作「ダノ」，列举并列，常带不满或唠叨
{% endhint %}

接在名词、句子之后，把几项列出来，语气里带情绪。

{% stepper %}
{% step %}
**列举（带不满）** - 相当于中文的「又是…又是…」\
高い**だの**まずい**だの**、文句ばかり。\
（又说贵又说难吃，净抱怨。）\
書類**だの**印鑑**だの**、持ち物が多い。\
（又是文件又是印章，要带的东西真多。）
{% endstep %}

{% step %}
**与「や」「とか」对照** - 「や」是中性列举，「とか」偏口语举例，「だの」带评价\
猫**や**犬が好きだ。（中性）／猫**とか**犬が好きだ。（口语）／猫**だの**犬**だの**、よく分からない。（听着就唠叨）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
「だの」自带的抱怨感很强，正式文书里不要用\
（写报告时列举，仍用「や」「および」）
{% endhint %}

{% hint style="success" %}
几个词与别的页面有重叠，对照着看更清楚：极端例示的「まで」与[系助词](xi-zhu-ci.md)页的「でも」，并列的「とか」「だの」与[格助词](ge-zhu-ci.md)页的「や」。
{% endhint %}
