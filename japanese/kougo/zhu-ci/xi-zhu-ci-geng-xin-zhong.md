# 系助词（更新中）

虽然学校语法中，系助词归类到副助词内，但此处依然细分出来。\
作为提示，此处提供一个实例作为参考：

|  分类 |     功能     |     影响范围    |   例词   |
| :-: | :--------: | :---------: | :----: |
| 系助词 | 主题提示、对比、强调 | 整个句子（从句）的逻辑 | は、も、こそ |
| 副助词 |   限定名词范围   |     单个词语    | だけ、ばかり |

{% tabs %}
{% tab title="系助词" %}
私は学生です。\
（我（主题）→是学生。）\
\[说明]\
• 「は」提示"我"为讨论主题\
• 中文自然翻译应为"我是学生"\
• 谓语「学生です」描述主题属性
{% endtab %}

{% tab title="副助词" %}
私が学生です。\
（我（主语）→是学生。）\
\[说明]\
• 「が」强调"我"是动作主体/信息焦点\
• 典型场景：

* 回答「誰が学生ですか？」（谁是学生？）
* 强调「他の人ではなく、私」（不是别人，就是我）  \
  • 此时「学生」是谓语而非宾语
{% endtab %}
{% endtabs %}

### は（wa）

{% hint style="success" %}
作为助词时，读作「ワ」；标注罗马音的场合，也应该标注（wa）
{% endhint %}

用于提示主题、或者用于对比主题。

{% stepper %}
{% step %}
**主题提示**​ - 将名词确立为句子谈论的中心\
文の主題を示す

私**は**椎名[^1]るりなの⭐です！\
（我**是**椎名るり⭐！）

象**は**&#x9F3B;_&#x304C;_&#x9577;い。\
（象的鼻子长。）\
（语法参考翻译：象的鼻**是**长的。）（「は」提示主题，「が」表属性）

これ**は**本だ。\
（这**是**书。）

明日[^2]**は**日曜日。\
（明天**是**周日。）

ヒーラー[^3]**は**何処だ？\
（自然翻译：奶呢？）（\*这是游戏用语）\
（语法参考翻译：治疗者**是**在哪里？（一般地，{**是**}在中文中会省略））

アメリカの卵の値段**は**高い。\
（自然翻译：美国鸡蛋价格很高）\
（语法参考翻译：美国的鸡蛋的价格**是**昂贵的。）
{% endstep %}

{% step %}
**对比强调**​ - 与其他事物形成明示或暗示的对比\
主題を対比して示す

魚**は**食べるが、肉**は**食べない。\
虽然吃鱼，但不吃肉（指鱼肉以外的肉）。

日本語**は**話せるが、英語**は**無理だ。\
我会说日语，但不会说英语。

今日**は**寒い。\
今天很冷。（但是昨天不冷）
{% endstep %}
{% endstepper %}

#### 替换规则

注：当提示主语时，「は」会取代「が」或「を」

> 本を読む → 本**は**読む\
> 彼が来た → 彼**は**来た

### か

不定代词或表疑问的标记。

{% stepper %}
{% step %}
表**疑问** - 接在句子的**谓语核心**后

いく**か**？\
（出发**吗**？）

彼は学生**か**？\
（他是学生**吗**？）

誰が来る？\
（谁会来？）\
（与疑问词（何、誰等）搭配时，句末「か」**可省略**）

何時出発**しますか**？\
（什么时候出发？）\
（与礼貌语、敬语搭配时，放在礼貌语后，而且**不可省略**）
{% endstep %}

{% step %}
表**不确定性**

雨が降る**か**どうか確認する。\
（确认一下会不会下雨。）

椎名さんが来る**か**わからない。\
（不知道椎名是否会来。）

できる**か**​試してみよう。\
（试试能不能做到。）\
（后面两个句子中，「**か**（どうか）」进行了省略，在大部分情况下，可以进行这样的省略）
{% endstep %}

{% step %}
**反语** - 通过否定句表强烈肯定

そんなことが許されよう**か**​！（=許されない！）\
"这种事怎能允许！"（=绝不允许！）
{% endstep %}
{% endstepper %}
