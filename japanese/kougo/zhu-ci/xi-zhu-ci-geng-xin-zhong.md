# 系助词（更新中）

虽然学校语法中，系助词归类到副助词内，但此处依然细分出来。\
作为提示，此处提供一个实例作为参考：

|  分类 |     功能     |     影响范围    |   例词   |
| :-: | :--------: | :---------: | :----: |
| 系助词 | 主题提示、对比、强调 | 整个句子（从句）的逻辑 | は、も、こそ |
| 副助词 |   限定名词范围   |     单个词语    | だけ、ばかり |

{% tabs %}
{% tab title="系助词" %}
私は学生です。\
（我（主题）→是学生。）\
\[说明]\
• 「は」提示"我"为讨论主题\
• 中文自然翻译应为"我是学生"\
• 谓语「学生です」描述主题属性
{% endtab %}

{% tab title="副助词" %}
私が学生です。\
（我（主语）→是学生。）\
\[说明]\
• 「が」强调"我"是动作主体/信息焦点\
• 典型场景：

* 回答「誰が学生ですか？」（谁是学生？）
* 强调「他の人ではなく、私」（不是别人，就是我）\
  • 此时「学生」是谓语而非宾语
{% endtab %}
{% endtabs %}

### は（wa）

{% hint style="success" %}
作为助词时，读作「ワ」；标注罗马音的场合，也应该标注（wa）
{% endhint %}

用于提示主题、或者用于对比主题。

{% stepper %}
{% step %}
**主题提示** - 将名词确立为句子谈论的中心\
文の主題を示す

私**は**椎名[^1]るりなの⭐です！\
（我**是**椎名るり⭐！）

象**は**&#x9F3B;_&#x304C;_&#x9577;い。\
（象的鼻子长。）\
（语法参考翻译：象的鼻**是**长的。）（「は」提示主题，「が」表属性）

これ**は**本だ。\
（这**是**书。）

明日[^2]**は**日曜日。\
（明天**是**周日。）

ヒーラー[^3]**は**何処だ？\
（自然翻译：奶呢？）（\*这是游戏用语）\
（语法参考翻译：治疗者**是**在哪里？（一般地，{**是**}在中文中会省略））

アメリカの卵の値段**は**高い。\
（自然翻译：美国鸡蛋价格很高）\
（语法参考翻译：美国的鸡蛋的价格**是**昂贵的。）
{% endstep %}

{% step %}
**对比强调** - 与其他事物形成明示或暗示的对比\
主題を対比して示す

魚**は**食べるが、肉**は**食べない。\
虽然吃鱼，但不吃肉（指鱼肉以外的肉）。

日本語**は**話せるが、英語**は**無理だ。\
我会说日语，但不会说英语。

今日**は**寒い。\
今天很冷。（但是昨天不冷）
{% endstep %}
{% endstepper %}

#### 替换规则

注：当提示主语时，「は」会取代「が」或「を」

> 本を読む → 本**は**読む\
> 彼が来た → 彼**は**来た

### か

不定代词或表疑问的标记。

{% stepper %}
{% step %}
表**疑问** - 接在句子的**谓语核心**后

いく**か**？\
（出发**吗**？）

彼は学生**か**？\
（他是学生**吗**？）

誰が来る？\
（谁会来？）\
（与疑问词（何、誰等）搭配时，句末「か」**可省略**）

何時出発**しますか**？\
（什么时候出发？）\
（与礼貌语、敬语搭配时，放在礼貌语后，而且**不可省略**）
{% endstep %}

{% step %}
表**不确定性**

雨が降る**か**どうか確認する。\
（确认一下会不会下雨。）

椎名さんが来る**か**わからない。\
（不知道椎名是否会来。）

できる**か**試してみよう。\
（试试能不能做到。）\
（后面两个句子中，「**か**（どうか）」进行了省略，在大部分情况下，可以进行这样的省略）
{% endstep %}

{% step %}
**反语** - 通过否定句表强烈肯定

そんなことが許されよう**か**！（=許されない！）\
"这种事怎能允许！"（=绝不允许！）
{% endstep %}
{% endstepper %}

### も

{% hint style="info" %}
与「は」同为提示类助词，读作「モ」，标注罗马音时写作（mo）
{% endhint %}

用于提示与前文同类的事物，表追加、并列，或强调数量与范围。

{% stepper %}
{% step %}
**追加** - 提示与前句同类的项，相当于中文的「也」\
私**も**行く。\
（我也去。）\
椎名[^1]さん**も**来る？\
（椎名也来吗？）\
（「は」换「も」，换掉的只是提示功能，句子其余部分不动）
{% endstep %}

{% step %}
**并列** - 同一助词的重复出现，把各项一起收进来\
猫**も**犬**も**好きだ。\
（猫和狗都喜欢。）\
寿司**も**ラーメン**も**食べたい。\
（寿司和拉面都想吃。）
{% endstep %}

{% step %}
**数量强调** - 接在数量词后，表"竟达、多达"\
三千円**も**した。\
（居然花了三千日元。）\
一時間**も**待った。\
（等了一个多小时。）\
（同为数量词，「しか」指"只有"，方向恰好相反）
{% endstep %}

{% step %}
**全否定与全肯定** - 与疑问词搭配，所指范围随句式翻转\
誰**も**来ない。\
（谁都没来。）\
何**も**ない。\
（什么都没有。）\
誰**も**知っている。\
（谁都知道。）\
（否定形取全否定，肯定形取全肯定）
{% endstep %}
{% endstepper %}

#### 替换规则

注：与「は」一样，「も」会取代「が」或「を」；接在「に・へ・で・と」之后时，与它们连写

> 本を読む → 本**も**読む\
> 彼が来た → 彼**も**来た\
> 東京に行く → 東京**にも**行く

### や

{% hint style="info" %}
读作「ヤ」，与「と」同属并列，接在名词后
{% endhint %}

用于并列同类事物，暗示列举并未穷尽。

{% stepper %}
{% step %}
**部分列举** - 举出代表性的事物，暗示还有别的\
猫**や**犬が好きだ。\
（喜欢猫、狗之类的。）\
（与「と」对照：猫**と**犬が好きだ。只指猫和狗，没有别的）

りんご**や**バナナを買った。\
（买了苹果、香蕉这些。）
{% endstep %}

{% step %}
**与「など」呼应** - 举出几项后收尾，明示未尽\
野菜**や**果物**など**を買った。\
（买了蔬菜、水果什么的。）\
猫**や**犬**など**、動物が好きだ。\
（猫、狗之类的动物都喜欢。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
关西方言里，「や」相当于断定助动词「だ」，与此处的并列用法无关\
そう**や**で。（関西腔：是这样没错。）
{% endhint %}

### こそ

{% hint style="info" %}
读作「コソ」，接在需要凸显的成分之后
{% endhint %}

用于把某一项提出来强调，相当于中文的「正是、才是」。

{% stepper %}
{% step %}
**强调** - 把焦点收到某一项上\
これ**こそ**私が探していたものだ。\
（这正是我在找的东西。）\
彼女**こそ**適任[^4]だ。\
（她才适合。）
{% endstep %}

{% step %}
**与「から」连用** - 原因被强调，相当于中文的「正因为」\
好きだ**からこそ**厳しく[^5]言う。\
（正因为喜欢，才说得严厉。）\
（接续时「こそ」放在「から」之后）
{% endstep %}

{% step %}
**承接对方的评价** - 把自己也放进强调的范围\
こちら**こそ**、すみません。\
（该道歉的是我才对。）\
いいえ、私**こそ**感謝しています。\
（哪里，我才要谢谢你。）
{% endstep %}
{% endstepper %}

#### 替换规则

注：与「は」不同，「こそ」接在「を」之后时，会保留「を」

> 本を読む → 本**をこそ**読む\
> 私が行く → 私**こそ**行く（接在名词后时，取代提示类的「は」「が」）

### でも

{% hint style="info" %}
读作「デモ」，由「で」＋「も」构成
{% endhint %}

用于提示极端事例或让步，相当于中文的「就连…也」「即使是…」。

{% stepper %}
{% step %}
**极端事例** - 举出极端例子，暗示其余更不必说\
子供**でも**分かる。\
（连小孩都懂。）\
この問題は小学生**でも**解ける。\
（这道题连小学生都会做。）
{% endstep %}

{% step %}
**举例（尚未确定）** - 相当于中文的「…之类的」\
お茶**でも**飲みませんか。\
（喝点茶之类的怎么样？）\
コーヒー[^6]**でも**買って帰るか。\
（买点咖啡什么的回去吧。）
{% endstep %}

{% step %}
**让步** - 与疑问词搭配，表「无论…都」\
何**でも**いい。\
（什么都行。）\
誰**でも**できる。\
（谁都做得到。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
出现在句首的「でも」是接续词，表转折，与此处的助词不同\
でも、そうとは限らない。（不过，也不一定。）
{% endhint %}

### しか

{% hint style="info" %}
读作「シカ」，必须与否定形式呼应，单用不成立
{% endhint %}

用于把范围收到唯一一项，相当于中文的「只有」。

{% stepper %}
{% step %}
**限定** - 与否定呼应，表"除此之外没有"\
水**しか**ない。\
（只有水。）\
財布に百円**しか**入っていない。\
（钱包里只有一百日元。）
{% endstep %}

{% step %}
**与「も」方向相反** - 同一个数量词，一个显其多，一个显其少\
一時間**も**待った。\
（等了一个多小时。）\
一時間**しか**待てない。\
（只能等一个小时。）
{% endstep %}

{% step %}
**惯用「〜しかない」** - 表别无他法，相当于中文的「只好」\
やる**しかない**。\
（只好做了。）\
電車が止まったので、歩いて帰る**しかなかった**。\
（电车停了，只好走着回去。）
{% endstep %}
{% endstepper %}

### ほか

{% hint style="info" %}
读作「ホカ」，汉字写作「他」，一般用假名书写
{% endhint %}

用于表排除，相当于中文的「除…之外」。

{% stepper %}
{% step %}
**排除** - 把某人某物排除在外，再谈其余的\
私**のほか**はみんな行った。\
（除了我，大家都去了。）\
彼**のほか**は誰も来なかった。\
（除了他，谁都没来。）
{% endstep %}

{% step %}
**追加（〜のほか〜も）** - 排除之余再补上一项\
東京**のほかにも**行きたい所がある。\
（除了东京，还有想去的地方。）\
（与「も」呼应时，句意从排除转为追加）
{% endstep %}

{% step %}
**别无他法（〜ほかない）** - 与「〜しかない」相近的惯用\
謝る**ほかない**。\
（只好道歉。）\
（同接否定语境，「しか」偏限定范围，「ほか」偏排除选项）
{% endstep %}
{% endstepper %}

[^2]: あした

[^3]: Healer

[^4]: てきにん

[^5]: きびしく

[^6]: Coffee
