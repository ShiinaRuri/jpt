# 四段活用

{% hint style="info" %}
在阅读本章节前，请确保您可以熟练背诵五十音图。另外，本页属**文语**（古典文法）章节，若还没有读过【用言活用-口语】，建议先读那里再回来。
{% endhint %}

首先，让我们知道，什么是四段活用（しだんかつよう）。

我们规定，词尾分布在「ア」「イ」「ウ」「エ」四个段上的动词，都叫做四段活用动词。

文语里绝大多数动词都归这一类。口语的【五段活用】就是它的后代——现代口语多出来的那个「オ」段（書こう）是后世才发达的，所以口语叫五段，文语只叫四段。

另外，文语中只有四段活用与ラ行変格活用有命令形，这一点请连同表格一起记住。

首先，整理一个变形表格。\
这个表格需要熟记。

| ガ | 泳ぐ  | 泳（およ） | が   | ぎ・い | ぐ   | ぐ   | げれ  | げ   |
| サ | 捜す  | 捜（さが） | さ   | し   | す   | す   | せれ  | せ   |
| ザ | ー   |       |     |     |     |     |     |     |
| タ | 勝つ  | 勝（か）  | た   | ち・っ | つ   | つ   | てれ  | て   |
| ダ | ー   |       |     |     |     |     |     |     |
| ナ | ー   |       |     |     |     |     |     |     |

### 表格备注：

* 连用形一栏有两部分：第一个是基本连用形，第二个是**音便形**（接「て」「たり」之类时用）。文语的音便分イ音便・ウ音便・促音便・撥音便四种，之后会单独讲。
* ナ行留空：文语里ナ行的动词只有「死ぬ」「往ぬ」两个，都属【ナ行変格活用】，请见ナ行変格活用那页。
* ア行・ヤ行・ザ行・ダ行在文语里没有常用的四段动词，故留空。
* 口语的【ワア行】在文语里就是ハ行。「会ふ」这类词是后世读音转到ワ行去的，表记才跟着变。
* 「思ふ」按历史假名遣写作ハ行，实际读音接近おもふ——本页保留文语写法。
* 任何动词的连体形单独使用，将作为一个名词。

## 如何看懂表格

我相信，新学习者，很可能看不懂这个表格。或者没有接受过正规日语学习的人，也有可能没有接触过这个表格。

在这里，将教会你如何看懂这类表格。因为下文会大量使用这种表格。

比方说，动词【咲く】为例。\
根据上面的变形规则，你可以整理出：

| 行 | 基本形 | 词干   | 未然形 | 连用形 | 终止形 | 连体形 | 已然形 | 命令形 |
| - | --- | ---- | --- | --- | --- | --- | --- | --- |
| カ | 咲く  | 咲（さ） | か   | き・い | く   | く   | けれ  | け   |

「咲く」是它的基本形，也是它的终止形。

如果你想要表达否定，那么将要变成未然形，再接「-ず」\
即「咲かず」。\
同理，要表达过去，则是「咲きけり」；要表达确定条件（既然……就……），则是「咲ければ」（已然形「咲けれ」接「ば」）。

如果您依然无法看懂这里的描述，那么我会在文语助动词及动词用法，加入最为简单的屈折用法演示。
