# 接续词

自立语、无活用，专管把**文与文、文节与文节、词与词**连起来——这一类就是接续词。它自己不充当句子的任何成分，只在缝上使力：没有它，前后两块还各自站着，只是接不上话。

与连体词一样，文语里的接续词**全部是「転成」来的**：或是别的品词的旧身，或由连语凝结而成。所以在它们身上，常能看见旧日的影子。

按资料的分法，接续词分作三组七类：

|  分類 |     機能     |  位置  |          例詞         |
| :-: | :--------: | :--: | :-----------------: |
|  並列 | 把对等的两项列在一起 | 主に文中 |      及び・並びに・又た      |
|  添加 |  往前件上再添一层  | 主に文中 |     且つ・しかうして・しかも    |
|  選択 |   二者之中择一   | 主に文中 |     或いは・はた・若しくは     |
|  順接 | 接住前件，顺势续下去 | 主に文頭 |   斯かれば・斯くて・然れば・故に   |
|  逆接 |  前件之后转个方向  | 主に文頭 | 斯かれども・然るは・しかし・然しかるに |
|  補足 |   补充限制或说明  | 必ず文頭 |        但し・即ち        |
|  転換 |   把话题调个头   | 必ず文頭 |   抑そもそも・さて・それ・然る程に  |

（资料上写的是「順態接続」「逆態接続」，与这里的順接・逆接是一回事。）

且つ 食ひ 且つ 語る。\
（边吃边谈。）\
\[说明]\
• 「且つ」把对等的两块连起来\
• 位置多在文中，前后两块各自都能成立\
• 它不充当任何成分，拿掉只是逻辑断了线
{% endtab %}

{% tab title="连体词" %}
あらゆる 花 咲けり。\
（所有的花都开了。）\
\[说明]\
• 「あらゆる」只接体言，充当连体修饰\
• 它连的是词与词，不管句子之间的逻辑\
• 与接续词一样，无活用、由転成而来
{% endtab %}
{% endtabs %}

### 並列

{% hint style="info" %}
把对等的两项列在一起，位置多在文中
{% endhint %}

{% stepper %}
{% step %}
**及び** - 表「以及」，把两项或数项并列\
酒 及び 肴 を 持て来たれ。（把酒和菜拿来。）
{% endstep %}

{% step %}
**並びに** - 与「及び」同路，层级更显正式\
父 並びに 母。（父亲以及母亲。）
{% endstep %}

{% step %}
**又た（また）** - 表「又、另外」\
又た 日 を 改めて 参らむ。（改日再来。）
{% endstep %}
{% endstepper %}

### 添加

{% hint style="info" %}
往前件上再添一层，位置多在文中
{% endhint %}

{% stepper %}
{% step %}
**且つ** - 表「并且、又…又…」\
且つ 食ひ 且つ 語る。（边吃边谈。）\
文 を 書き 且つ 絵 を 描く。（写文章，并且作画。）
{% endstep %}

{% step %}
**しかうして（而して）** - 表「然后、于是」\
しかうして 事 遂に 成れり。（于是事情终于成了。）
{% endstep %}

{% step %}
**しかも（而も）** - 表「而且、却」\
雪 降り しかも 風 吹く。（下着雪，而且吹着风。）
{% endstep %}
{% endstepper %}

### 選択

{% hint style="info" %}
二者之中择一，位置多在文中；与「はた」呼应时，语气更显犹疑
{% endhint %}

{% stepper %}
{% step %}
**或いは（或は）** - 表「或者」\
或いは 酒、或いは 茶。（或酒，或茶。）
{% endstep %}

{% step %}
**はた** - 表「或者、要不」，多与「或いは」前后呼应\
或いは 行き、はた 止まらむ。（要么去，要么作罢。）
{% endstep %}

{% step %}
**若しくは** - 表「或者」，多用于选择\
紙 若しくは 帛 に 書く。（写在纸或帛上。）
{% endstep %}
{% endstepper %}

### 順接

{% hint style="info" %}
接住前件，顺势续下去；位置多在文头
{% endhint %}

{% stepper %}
{% step %}
**斯かれば（しかれば）** - 表「既然如此、那么」\
斯かれば 我 も 行かむ。（既然如此，我也去。）
{% endstep %}

{% step %}
**斯くて（かくて）** - 表「就这样、于是」\
斯くて 年 暮れぬ。（就这样一年到头了。）
{% endstep %}

{% step %}
**然れば（されば）** - 表「因此」\
然れば 人 皆 喜べり。（因此人人都欢喜。）
{% endstep %}

{% step %}
**故に（ゆゑに）** - 表「所以」，多接原因句\
雨 降り 故に 出でず。（因为下雨，所以不出门。）
{% endstep %}
{% endstepper %}

### 逆接

{% hint style="info" %}
前件之后转个方向；位置多在文头
{% endhint %}

{% stepper %}
{% step %}
**斯かれども（しかれども）** - 表「然而、话虽如此」\
斯かれども 我 は 行かず。（话虽如此，我是不去的。）
{% endstep %}

{% step %}
**然るは（さるは）** - 表「其实、说来」\
然るは、これ 我 が 罪 なり。（其实这是我的过错。）
{% endstep %}

{% step %}
**しかし** - 表「但是」\
しかし 事 竟に 成らず。（但是事情终究没成。）
{% endstep %}

{% step %}
**然しかるに（しかるに）** - 表「然而」，把前件整个推翻\
然しかるに、人 は 皆 知れり。（然而人们都知道。）
{% endstep %}
{% endstepper %}

### 補足

{% hint style="info" %}
补充限制或说明；位置必在文头，劈头一笔补上去
{% endhint %}

{% stepper %}
{% step %}
**但し（ただし）** - 表「不过、但」，加一条限制\
但し 雨 の 日 は 除く。（但雨天除外。）
{% endstep %}

{% step %}
**即ち（すなはち）** - 表「即、也就是说」\
即ち これ 我 が 求むる もの なり。（这正是我所求之物。）
{% endstep %}
{% endstepper %}

### 転換

{% hint style="info" %}
把话题调个头，位置必在文头
{% endhint %}

{% stepper %}
{% step %}
**抑そもそも** - 表「话说回来」，在开头重提话题\
抑そもそも、此の 事 は 何 より 起こりしか。（话说回来，这事是从何而起的呢。）
{% endstep %}

{% step %}
**さて** - 表「那么」，把话头带开\
さて、次 の 事 を 申さむ。（那么，接下来说下一件事。）
{% endstep %}

{% step %}
**それ** - 表「那么、且说」，提醒对方转入新话\
それ、今宵 の 月 を 見よ。（那么，请看今夜的月亮。）
{% endstep %}

{% step %}
**然る程に（さるほどに）** - 表「就这么着」，在物语里多用于另起话头\
然る程に、月 も 出でにけり。（就这么着，月亮也出来了。）
{% endstep %}
{% endstepper %}

### 附注：缝上的那几针

副词管修饰，连体词管接体言，接续词管的是句子之间的缝。它不像用言那样能变形，也不像名词那样能当主语——它的全部本钱，就是知道该往哪儿缝：对等的缝合在中间，承前件的缝摆在文头。
