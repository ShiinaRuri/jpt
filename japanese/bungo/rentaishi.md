# 连体词

自立语、无活用，本身不能单独充当句子的任何成分，只能**站在体言之前**——这一类就是连体词。它的活儿只有一件：把后头那个体言指出来、或限定住。

名字本身就把用法说完了：**連体，就是接体言**。

与接续词一样，文语中的连体词**全部是「転成」来的**：或是别的品词的旧身，或是连语凝结而成的化石。所以它们形态固定，一辈子不改样；也不能像形容词那样接「て」「ば」。

|   連体詞   |   意味   |    例   |
| :-----: | :----: | :----: |
|   あらゆる  |   全ての  | あらゆる 花 |
|   いかなる  |   どんな  | いかなる 罪 |
|    ある   | とある・或る |  ある 山  |
|  さる（然る） |  そのような |  さる 由  |
|    この   |   近称   |  この 文  |
|    その   |   中称   |  その 人  |
|  かの（彼の） |   远称   |  かの 人  |
| 例の（れいの） |  いつもの  |  例の 所  |

第一要紧的，是把它与**形容词・形容动词的連体形**分开看。两者都站在体言前面，可一个是词类，一个是活用形：

{% tabs %}
{% tab title="连体词" %}
あらゆる 花 咲きぬ。\
（所有的花都开了。）\
\[说明]\
• 「あらゆる」无活用，形态永远不变\
• 没有原形可还原——它本来就是这一副样子\
• 只能站在体言前，离开体言便什么都不是
{% endtab %}

{% tab title="形容詞の連体形" %}
美しき 花 咲きぬ。\
（美丽的花开了。）\
\[说明]\
• 「美しき」是「美し」的連体形，随活用而变\
• 换个接续，它就变回「美しく」「美し」\
• 同是修饰体言，一个是化石，一个是变形
{% endtab %}
{% endtabs %}

### あらゆる・いかなる

{% hint style="info" %}
前者表「所有的」，后者表「无论怎样的」——都把一个整体罩在里面
{% endhint %}

{% stepper %}
{% step %}
**あらゆる** - 表「所有的」\
あらゆる 花 咲きぬ。（所有的花都开了。）\
あらゆる 事 を 見てき。（什么都要亲眼看过。）
{% endstep %}

{% step %}
**いかなる** - 表「无论怎样的」，常用于让步\
いかなる 罪 も 赦されず。（无论何罪，皆不获赦。）
{% endstep %}
{% endstepper %}

### ある・さる

{% hint style="info" %}
一个指「某个」，一个指「那样的」；都带一点不明说的语气
{% endhint %}

{% stepper %}
{% step %}
**ある** - 表「某个、某一个」\
ある 山 に 庵 ありけり。（某座山里，有一间草庵。）
{% endstep %}

{% step %}
**さる（然る）** - 表「那样的、这般的」\
さる 由 ありて 参らぬ。（因有这般缘由，未能前去。）
{% endstep %}
{% endstepper %}

### この・その・かの

{% hint style="info" %}
近・中・远三栏的指示；文语的远称用「かの」，「あの」是后世的形状
{% endhint %}

{% stepper %}
{% step %}
**この** - 近称，指眼前或刚提到的东西\
この 文 を 見ばや。（想看看这封信。）
{% endstep %}

{% step %}
**その** - 中称，指对方或上文提到的\
その 人 こそ 我 が 父 なれ。（那人正是我父。）
{% endstep %}

{% step %}
**かの（彼の）** - 远称，指两边都知道的远处之物\
かの 人 は 今 いづく に か。（那人如今在何处。）
{% endstep %}
{% endstepper %}

### 例の

{% hint style="info" %}
指「双方都知道的那个」，语气近于「你知道的那个」
{% endhint %}

{% stepper %}
{% step %}
**例の（れいの）** - 表「往常那个、知名的那个」\
例の 所 に 佇みけり。（伫立在往常那处。）
{% endstep %}
{% endstepper %}

### 附注：化石的那一半

连体词不能用「て」「ば」接续，也不能住到主语或述语的位置上去——把后面的体言拿走，它就没有落脚的地方。这一点与接续词恰好成对：接续词若不接前后两段，也就成了孤零零一个词。

它们又都是転成来的，所以细看每枚词，都能看出旧身份的影子——这一点比死记词表好玩多了。

（例句为编制时所补，日后核正。另：口语里的「大きな」「いろんな」也算连体词，这类词哪个时代都在从别的品词里往外长。）
