# 副词

{% hint style="info" %}
本页属**文语**（古典文法）章节，例句与用词都按文语来。
{% endhint %}

## 副词介绍

副词也是**无活用**的一类：形态不随语法改变，也不能像名词那样被助词领着当主语。它的活儿很专一——修饰用言。

前面几页讲的都是会变形的词；到副词这儿，事情简单了：它不变形，只负责把用言的意思往某个方向推。「いと美し」与「はなはだしく悲し」，词没变，挂上不同的副词，分量就不同。

副词按作用大致分三类：

* **表状态的副词**：把动作、状态的样式描出来（やがて・かく・ひたぶるに）。
* **表程度的副词**：把性质、动作的程度量出来（いと・いたく・はなはだ）。
* **陈述副词**：牵住句末的陈述方式（え〜ず・ゆめ〜な・よも〜じ）。这一类要与句尾的助词、助动词呼应着用。

## 表状态的副词

描摹动作与状态的样式：怎么做、什么样子、什么时候。

| 副詞    | 意味       | 例          |
| ----- | -------- | ---------- |
| やがて   | そのまま・すぐに | やがて 出でぬ    |
| つとめて  | 早朝に      | つとめて 起く    |
| たちまち  | すぐに・急に   | たちまち 散りぬ   |
| ゆくりなく | 思いがけず    | ゆくりなく 訪れぬ  |
| さながら  | そのまま     | さながら 雪のごとし |
| やをら   | そっと・静かに  | やをら 立ちぬ    |
| かく    | このように    | かく 言ふ      |
| しか    | そのように    | しか あり      |
| さ     | そう       | さ 思ふ       |

### 表格备注：

* 这一类管的是「怎么做的」：时间、样态都归在这里。
* 「かく」（このように）与「さ」「しか」（そう・そのように）是一套指示副词，指向上文刚提过的事。
* 状态副词不要求句尾配特定形态，用法与口语的副词相近，认词就能读懂大半。
* 「やがて」在文语里多是「そのまま」「すぐに」，比现代口语的「不久之后」要急一些。

## 表程度的副词

量出性质与动作的深浅。

| 副詞   | 意味         | 例       |
| ---- | ---------- | ------- |
| いと   | とても・たいそう   | いと 美し   |
| いたく  | ひどく・非常に    | いたく 悲し  |
| はなはだ | はなはだしく・非常に | はなはだ 寒し |
| ことに  | 特に         | ことに 涼し  |
| あまた  | たくさん       | あまた あり  |
| やや   | 少し・いくらか    | やや 涼し   |
| いささか | 少し・わずか     | いささか 見ゆ |

### 表格备注：

* 程度副词大多修饰形容词与动词，位置在被修饰语之前。
* 「いと」在文语里出场极多，翻成「很」「颇」「太」，看上下文定。
* 程度副词本身不要求句尾配什么形态——这一点正与下面的陈述副词成对照。
* 得注意「つゆ」「たえて」「をさをさ」这一挂：它们跟句尾的否定拴在一起，所以归到陈述副词那边去。

## 陈述副词

与句末的陈述方式相互呼应的副词。单看它自己，意思讲不全；配上句尾的助词、助动词，语气才落地。按呼应的种类分作八类：

| 種類     | 副詞                     | 呼応する語     | 例                      |
| ------ | ---------------------- | --------- | ---------------------- |
| 打消     | あへて・大方・さらに・たえて・つゆ・をさをさ | ず・じ・まじ・なし | あへて 見ず／つゆ 思はず          |
| 禁止     | ゆめ・ゆめゆめ・な              | な・そ（終助詞）  | ゆめ 言ふな／な 語りそ           |
| 假定     | もし・たとひ・よし              | ば・とも      | もし 雨 降らば／たとひ 死すとも      |
| 推量     | よも                     | じ・む       | よも 助け あらじ              |
| 比喻     | たとへば・あたかも              | ごとし・やうなり  | たとへば 雪のごとし／あたかも 夢のやうなり |
| 当然     | まさに                    | べし・まじ     | まさに 行くべし               |
| 希望     | ねがはくは・せめて              | む・まし・たまへ  | ねがはくは 告げたまへ            |
| 疑問（反語） | いかで・など・なんぞ             | か・かは・や    | いかで 忘れむや／などか 言はざらむ     |

### 表格备注：

* 打消那一片最厚：あへて・大方・さらに・たえて・つゆ・をさをさ，每一项都得配上句尾的否定才成立。试着单独摆一个「つゆ」出来——它什么也没说，对吧？
* 推量那一栏单薄得多，主干几乎只有「よも」一个。原因不复杂：推量的活儿大半由助動詞（む・じ・けむ・らむ）自己扛着，副詞只补一点语气。
* 假定与禁止这两类，呼应的对象不是助動詞而是助詞：「〜ば」「〜とも」与終助詞「そ」。
* 人一多，界限难免打架：「いかで」在反語里最常见，配上「まし」时又能往希望那边靠；分类表只是路标，读到一句真话，还得看句尾那位伙伴站哪边。
