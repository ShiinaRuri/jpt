# 用言活用-文语

日语是屈折语，用言需要用不同的形态来改变其本身意思。这一点，文语与口语没有分别。

分别在于：今天口语里的那些形态，本来就是从文语传下来的。文语留得更全，表也更整齐。

在文语中，用言同样有六种语义形态；而且文语的用言不只适用于动词，形容词和形容动词也要按这套形态变形。

此页面仅作粗略介绍，详细学习请阅读详细章节。

文语有下面六种语义屈折性：

## 未然形

否定的「-ず」、受身・可能・自発的「-る（らる）」、使役的「-す（さす）」、推量的「-む」等接续的形态。另，接「-ば」可表假定（もし…なら）。

| 原型 | 否定  | 推量  | 假定  |
| -- | --- | --- | --- |
| 書く | 書かず | 書かむ | 書かば |

## 連用形

接续过去「-き・けり」、完了「-つ・ぬ」、希望「-たし」等助动词的形态，也是接续「-て」的形态。如果本形态后面不接任何词语，那么将该**动词作为名词使用**。

| 原型 | 接「て」 | 表过去  | 表完了 | 作名词 |
| -- | ---- | ---- | --- | --- |
| 書く | 書きて  | 書きけり | 書きぬ | 書き  |

## 終止形

不做任何接续，或者在句末作句子的终止。

> 文を 書く。\
> 写文章。

不过文语有一门口语里没有的规矩，叫**係り結び**：句中若出现「ぞ・なむ・や・か」，句末要用連体形结；出现「こそ」，要用已然形结。文语的句尾，得看助词的眼色。

## 連体形

接续其他**体言**的形态；同时也是係り結び中「ぞ・なむ・や・か」的结句形态。

> これは 我の 書く 文 なり。\
> 这是我写的文章。

## 已然形

接续「-ば」「-ども」的形态。已然形接「-ば」表顺接的确定条件（既然…就…），接「-ども」表逆接的确定条件（虽然…却…）。係り結び的「こそ」也用已然形结句。

| 原型 | 顺接（＋ば） | 逆接（＋ども） |
| -- | ------ | ------- |
| 書く | 書けば    | 書けども    |

口语里与之相对的是**仮定形**，接的也是「-ば」；但口语的仮定形只管假定，文语的已然形说的是已经成立的前提——这两者最容易被混过去，后面的活用页里会反复提。

## 命令形

文语中只有四段活用和ラ行変格活用有命令形。上一段・下一段・上二段・下二段・カ変・サ変・ナ変都没有命令形，要下命令得绕道说。

| 原型     | 命令形 |
| ------ | --- |
| 書く（四段） | 書け  |
| あり（ラ変） | あれ  |
