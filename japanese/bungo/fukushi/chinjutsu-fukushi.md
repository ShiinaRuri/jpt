# 陈述副词

文语里有一类副词，光看它自己讲不出完整意思——它像一根绳子，另一头拴在句末。说「つゆ」，句尾若是否定缺席，句子就不成立；说「ゆめ」，句末不接禁止，话也落不了地。这类副词，文法上叫**陈述副词**，也叫「呼応の副詞」。

本页先摆一张分类总表，再按栏拆开看。表中「呼応する表現」那一栏，就是绳子另一头拴着的那位。

|   分類   |    機能   |             呼応する表現            |      例詞     |
| :----: | :-----: | :---------------------------: | :---------: |
|   打消   |  让否定成立  | 助動詞「ず」「じ」「まじ」／接続助詞「で」／形容詞「無し」 | あへて・つゆ・え・いさ |
|   禁止   | 阻止对方做某事 |           終助詞「な」「そ」           |     ゆめ・な    |
|   假定   |   提出条件  |           助詞「ば」「とも」           |  もし・たとひ・よし  |
|   推量   |  推测、婉曲  |       助動詞「む」「じ」「けむ」「らむ」       |      待核     |
|   比喻   |    比况   |          「ごとし」「やうなり」          |  たとへば・あたかも  |
|   当然   |  应当、不应当 |          助動詞「べし」「まじ」          |     まさに     |
|   希望   |    愿望   |      助動詞「む」「まし」／補助動詞「たまへ」     |  ねがはくは・せめて  |
| 疑問（反語） |  疑问、反语  |           係助詞「か」「や」           |  いかで・など・なんぞ |

除打消一栏的条目外，其余各栏仍是草案，日后逐栏核正。

つゆ 思はず。\
（丝毫也不思念。）\
\[说明]\
• 「つゆ」要求句尾取否定\
• 句尾一改成肯定，句子当场就塌\
• 拴住它的是「ず」，而不是它自己
{% endtab %}

{% tab title="状态副词" %}
やがて 出でぬ。\
（就那么出去了。）\
\[说明]\
• 「やがて」只管描摹动作的样式\
• 句尾肯定还是否定，它一概不管\
• 把它拿掉，句子照样站得住
{% endtab %}
{% endtabs %}

### 打消

{% hint style="info" %}
呼应对象有四个去处：助動詞「ず」「じ」「まじ」、接続助詞「で」、形容詞「無し」
{% endhint %}

把整句话推向否定。这一栏最厚，分作几组看：

{% stepper %}
{% step %}
**一般打消** - 与「ず」「じ」「まじ」「で」「無し」呼应\
あへて 見ず。（完全不去看。）\
おほかた 音も せず。（一点儿声音也没有。）\
さらに 思はず。（根本不想。）\
絶えて 便りも なし。（半点音信也无。）\
露 も 見えず。（丝毫不见。）
{% endstep %}

{% step %}
**をさをさ** - 与否定呼应，表「ほとんど…ない」\
をさをさ 外にも 出でず。（几乎连门也不出。）
{% endstep %}

{% step %}
**まだ** - 与否定呼应，表「还没…」\
まだ 夜も 明けず。（天还没亮。）
{% endstep %}

{% step %}
**え** - 只与否定搭配，表「做不到…」\
え 言はず。（说不出口。）\
え 見で 帰りぬ。（没能见上一面就回去了。）
{% endstep %}

{% step %}
**よも（よもや）** - 单与「じ」呼应，表强烈的否定推量\
よも 我を 捨てじ。（总不至于丢下我吧。）
{% endstep %}

{% step %}
**いさ（いざ）** - 与「知らず」焊在一起\
いさ 知らず。（不知道，说不上来。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
「つゆ」「たえて」「をさをさ」这一挂，句尾若不否定，句子就读不通。它们不是修饰词，是骨架。
{% endhint %}

### 禁止

{% hint style="info" %}
呼应对象是終助詞「な」「そ」：副詞「ゆめ」配「な」，「な」再配「そ」——两头一夹，禁止才立住
{% endhint %}

{% stepper %}
{% step %}
**ゆめ…な** - 强烈禁止\
ゆめ 人に 語るな。（千万不要对人说。）\
ゆめゆめ 忘るな。（万勿忘怀。）
{% endstep %}

{% step %}
**な…そ** - 副詞「な」在前、終助詞「そ」在后，前后夹住一句\
な 言ひそ。（别说。）
{% endstep %}
{% endstepper %}

### 假定

{% hint style="info" %}
呼应的是助詞「ば」「とも」，不是助動詞——条件由它们标出
{% endhint %}

{% stepper %}
{% step %}
**もし…ば** - 假定条件\
もし 雨 降らば。（要是下雨的话。）
{% endstep %}

{% step %}
**たとひ…とも** - 逆接假定，先让步再转折\
たとひ 死すとも。（纵然一死。）
{% endstep %}

{% step %}
**よし…とも** - 与「たとひ」同路，语气更淡一些\
よし 遅くとも。（纵使迟了。）
{% endstep %}
{% endstepper %}

### 推量

{% hint style="info" %}
此栏条目待核：推量的活儿大半由助動詞（む・じ・けむ・らむ）自己扛着，能固定呼应的副詞相应就少
{% endhint %}

眼下唯一稳当的一位是「よも」，而它已被归进打消那一片（配「じ」）——「よも…じ」说到底是「不至于…吧」，本来就在否定。

### 比喻

{% hint style="info" %}
呼应对象是「ごとし」「やうなり」，把两件事拴到一起做比
{% endhint %}

{% stepper %}
{% step %}
**たとへば…ごとし** - 明喻\
たとへば 雪の ごとし。（譬如说，就像雪一样。）
{% endstep %}

{% step %}
**あたかも…やうなり** - 比况，带一点断定的味道\
あたかも 夢の やうなり。（宛如一场梦。）
{% endstep %}
{% endstepper %}

### 当然

{% hint style="info" %}
呼应对象是「べし」「まじ」——一个表应当，一个表不该
{% endhint %}

{% stepper %}
{% step %}
**まさに…べし** - 当然、適当\
まさに 行くべし。（正该去。）
{% endstep %}

{% step %}
**まさに…まじ** - 反向的当然\
まさに 侮る まじ。（不可轻慢。）
{% endstep %}
{% endstepper %}

### 希望

{% hint style="info" %}
呼应对象是助動詞「む」「まし」（含「てまし」）与補助動詞「たまへ」；此栏条目同样待核
{% endhint %}

{% stepper %}
{% step %}
**ねがはくは…たまへ** - 请求式的愿望\
ねがはくは 告げ たまへ。（恳请相告。）
{% endstep %}

{% step %}
**せめて…てまし** - 反事实的愿望\
せめて 一目 見てまし。（要是能看上一眼就好了。）
{% endstep %}
{% endstepper %}

### 疑問（反語）

{% hint style="info" %}
呼应对象是係助詞「か」「や」——疑问与反語共用一套标记，靠上下文分辩
{% endhint %}

{% stepper %}
{% step %}
**いかで…か（や）** - 多为反語：以否定的形式表强烈肯定\
いかで 忘れむ や。（怎么忘得了呢。）
{% endstep %}

{% step %}
**など・なんぞ…か** - 同上，语气更近口语一些\
などか 言はざらむ。（怎么会不说呢。）
{% endstep %}
{% endstepper %}

***

### 附注：为什么叫「陈述」副词

状态副词管「怎么做」，程度副词管「多少」，这两类都在句子内部打转。陈述副词管的是另一件事——整句话怎么收尾：肯定、否定、禁止、推测、愿望，语气由它与句尾一起定。所以文法书把它单独拎出来，一栏一栏排给你看。
