# 陈述副词

文语里有一类副词，光看它自己讲不出完整意思——它像一根绳子，另一头拴在句末。说「つゆ」，句尾若是否定缺席，句子就不成立；说「ゆめ」，句末不接禁止，话也落不了地。这类副词，文法上叫**陈述副词**，也叫「呼応の副詞」。

本页先摆一张分类总表，再按栏拆开看。表中「呼応する表現」那一栏，就是绳子另一头拴着的那位。

|   分類   |    機能   |             呼応する表現            |                        例詞                        |
| :----: | :-----: | :---------------------------: | :----------------------------------------------: |
|   打消   |  让否定成立  | 助動詞「ず」「じ」「まじ」／接続助詞「で」／形容詞「無し」 |     あへて・おほかた・大方・さらに・たえて・つゆ・露・をさをさ・まだ・え・よも・いさ     |
|   禁止   | 阻止对方做某事 |           終助詞「な」「そ」           |                     ゆめ・ゆめゆめ・な                    |
|   假定   |   提出条件  |           助詞「ば」「とも」           |         もし（若し）・たとひ（仮令）・たて（縦）・たてしや（縦しや）・よし        |
|   推量   |  推测、婉曲  |       助動詞「む」「じ」「けむ」「らむ」       |        或いは・蓋し・如何許り・恐らく・必ず・定めて・宜（むべ）・諾（うべ）        |
|   比喻   |    比况   |          「ごとし」「やうなり」          |              たとへば・あたかも（恰も）・さながら（宛ら）              |

つゆ 思はず。\

• 「つゆ」要求句尾取否定\

やがて 出でぬ。\
（就那么出去了。）\
\[说明]\
• 「やがて」只管描摹动作的样式\
• 句尾肯定还是否定，它一概不管\
• 把它拿掉，句子照样站得住
{% endtab %}

### 打消

{% hint style="info" %}
呼应对象有四个去处：助動詞「ず」「じ」「まじ」、接続助詞「で」、形容詞「無し」
{% endhint %}

把整句话推向否定。这一栏最厚，分作几组看：

{% stepper %}
{% step %}
**一般打消** - 与「ず」「じ」「まじ」「で」「無し」呼应\
あへて 見ず。（完全不去看。）\
おほかた 音も せず。（一点儿声音也没有。）\
さらに 思はず。（根本不想。）\
絶えて 便りも なし。（半点音信也无。）\
露 も 見えず。（丝毫不见。）
{% endstep %}

{% step %}
**をさをさ** - 与否定呼应，表「ほとんど…ない」\
をさをさ 外にも 出でず。（几乎连门也不出。）
{% endstep %}

{% step %}
**まだ** - 与否定呼应，表「还没…」\
まだ 夜も 明けず。（天还没亮。）
{% endstep %}

{% step %}
**え** - 只与否定搭配，表「做不到…」\
え 言はず。（说不出口。）\
え 見で 帰りぬ。（没能见上一面就回去了。）
{% endstep %}

{% step %}
**よも（よもや）** - 单与「じ」呼应，表强烈的否定推量\
よも 我を 捨てじ。（总不至于丢下我吧。）
{% endstep %}

{% step %}
**いさ（いざ）** - 与「知らず」焊在一起\
いさ 知らず。（不知道，说不上来。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
「つゆ」「たえて」「をさをさ」这一挂，句尾若不否定，句子就读不通。它们不是修饰词，是骨架。
{% endhint %}

### 禁止

{% hint style="info" %}
呼应对象是終助詞「な」「そ」：副詞「ゆめ」配「な」，「な」再配「そ」——两头一夹，禁止才立住
{% endhint %}

{% stepper %}
{% step %}
**ゆめ…な** - 强烈禁止\
ゆめ 人に 語るな。（千万不要对人说。）\
ゆめゆめ 忘るな。（万勿忘怀。）
{% endstep %}

{% step %}
**な…そ** - 副詞「な」在前、終助詞「そ」在后，前后夹住一句\
な 言ひそ。（别说。）
{% endstep %}
{% endstepper %}

### 假定

{% hint style="info" %}
呼应的是助詞「ば」「とも」：顺接用「ば」，逆接用「とも」——条件由它们标出
{% endhint %}

{% stepper %}
{% step %}
**もし（若し）…ば** - 假定条件\
もし 雨 降らば。（要是下雨的话。）
{% endstep %}

{% step %}
**たとひ（仮令）…とも** - 逆接假定，先让步再转折\
たとひ 死すとも。（纵然一死。）
{% endstep %}

{% step %}
**たて（縦）・たてしや（縦しや）** - 与「たとひ」同路，语气更淡\
たて 雨 降るとも。（纵使下雨。）\
たてしや 人 知るとも。（纵使人知道了。）
{% endstep %}

{% step %}
**よし…とも** - 表让步，常用于「就算…也无妨」\
よし 遅くとも。（纵使迟了。）
{% endstep %}
{% endstepper %}

### 推量

{% hint style="info" %}
呼应对象是推量の助動詞「む」「じ」「けむ」「らむ」；此栏条目依资料补入
{% endhint %}

{% stepper %}
{% step %}
**或いは** - 表「或许、也许」\
或いは 雨 降らむ。（或许会下雨。）
{% endstep %}

{% step %}
**蓋し（けだし）** - 表「想来、恐怕」，多用于提出判断\
蓋し 彼 の 罪 ならむ。（想来，大概是他之过。）
{% endstep %}

{% step %}
**如何許り（いかばかり）** - 表「不知有多么…」，与推量呼应\
いかばかり 嬉しかりけむ。（不知他有多高兴。）
{% endstep %}

{% step %}
**恐らく** - 表「恐怕」，常与「じ」相配\
恐らく 間に合はじ。（恐怕赶不上了。）
{% endstep %}

{% step %}
**必ず** - 表「必定」，把推量的语气压实\
必ず 事 成らむ。（事情必定能成。）
{% endstep %}

{% step %}
**定めて（さだめて）** - 表「想必是…」，多与「けむ」「む」呼应\
定めて 御心 も 乱れ けむ。（想必您的心也乱了。）
{% endstep %}

{% step %}
**宜（むべ）・諾（うべ）** - 表「もっともだ、说得也是」，多置于句首照应后文\
（例句待补。）
{% endstep %}
{% endstepper %}

### 比喻

{% hint style="info" %}
呼应对象是「ごとし」「やうなり」，把两件事拴到一起做比
{% endhint %}

{% stepper %}
{% step %}
**たとへば…ごとし** - 明喻\
たとへば 雪の ごとし。（譬如说，就像雪一样。）
{% endstep %}

{% step %}
**あたかも（恰も）…やうなり** - 比况，带一点断定的味道\
あたかも 夢の やうなり。（宛如一场梦。）
{% endstep %}

{% step %}
**さながら（宛ら）…ごとし** - 表「宛如」，与「ごとし」相配\
さながら 雪の ごとし。（宛如雪一般。）
{% endstep %}
{% endstepper %}

{% hint style="info" %}
「さながら」在状态副词那栏也占一位（当「そのまま」讲）；与「ごとし」相配时，它就转到了比喻这一栏
{% endhint %}

### 当然

{% hint style="info" %}
呼应对象是「べし」「まじ」——一个表应当，一个表不该
{% endhint %}

{% stepper %}
{% step %}
**まさに（当に）…べし** - 当然、適当\
まさに 行くべし。（正该去。）
{% endstep %}

{% step %}
**まさに（当に）…まじ** - 反向的当然\
まさに 侮る まじ。（不可轻慢。）
{% endstep %}

{% step %}
**すべからく（須く）…べし** - 表「应当」，多见于汉文训读体\
すべからく 学ぶ べし。（应当学习。）
{% endstep %}
{% endstepper %}

### 希望

{% hint style="info" %}
呼应对象是助動詞「む」「まし」（含「てまし」）与補助動詞「たまへ」
{% endhint %}

{% stepper %}
{% step %}
**いかで（争で）…てまし** - 反实的愿望，表「总想…、务必…」\
いかで 一目 見てまし。（总想见上一面。）
{% endstep %}

{% step %}
**ひとへに（偏に）** - 表「专心一意」，多与愿望、祈请同现\
ひとへに 願ひ たてまつる。（一心祈愿。）
{% endstep %}

{% step %}
**なにとぞ（何卒）** - 表「务必、恳请」，下接请求或愿望\
なにとぞ 御 許し たまへ。（万望恕罪。）
{% endstep %}
{% endstepper %}

### 疑問（反語）

{% hint style="info" %}
呼应对象是係助詞「か」「や」——疑问与反語共用一套标记，靠上下文分辩
{% endhint %}

{% stepper %}
{% step %}
**あに（豈に）** - 反語，与「や」「か」相配，以否定形式表强烈肯定\
あに 忘れむ や。（怎么会忘。）
{% endstep %}

{% step %}
**なんぞ（何ぞ）・など・なでふ** - 疑问・反语一族，表「为何、怎么」\
なんぞ 恐るる こと の あらむ。（有什么可怕的呢。）\
などか 言はざらむ。（怎么会不说呢。）\
なでふ こと か 言ふ。（说的什么话呢。）
{% endstep %}

{% step %}
**いづくんぞ（安んぞ）** - 反語，相当于「どうして…か」\
いづくんぞ 知らむ。（怎么会知道。）
{% endstep %}

{% step %}
**いかが（如何）・いかん（何如）** - 疑问，相当于「如何、怎样」\
いかが 思す。（您意下如何。）\
いかん せむ。（该如何是好。）
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
「いかで」在反語里也露过面（配「か」「や」）；本页按资料把它归进希望（配「てまし」那一路）。读文时先看句尾站谁，再定它算哪栏。
{% endhint %}

### 附注：为什么叫「陈述」副词

状态副词管「怎么做」，程度副词管「多少」，这两类都在句子内部打转。陈述副词管的是另一件事——整句话怎么收尾：肯定、否定、禁止、推测、愿望，语气由它与句尾一起定。所以文法书把它单独拎出来，一栏一栏排给你看。
