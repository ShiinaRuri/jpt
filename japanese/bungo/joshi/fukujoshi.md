# 副助詞

附在各种词后头，替那个词添上意味——这一类就是副助词。它不牵动句末，也不指名格，管的是「这个成分在句中占多大分量」。

|  副助詞 |   意味  |        译法       |
| :--: | :---: | :-------------: |
|  だに  | 類推／限定 |   〜さえ／せめて〜だけでも  |
|  すら  |   類推  | 〜さえ（比 だに 更古的调子） |
|  さへ  |   添加  |       〜までも      |
|  のみ  |   限定  |       〜だけ       |
|  ばかり | 程度・限定 |     〜ほど／〜だけ     |
|  まで  | 限定・添加 |       〜まで       |
|  など  |   例示  |       〜など       |
| し・しも |   強意  |   现代语几乎不留，难直译   |

* 花 だに 散る（连花都落了）——類推
* 今 ひとたび 逢ひ 見 だに せ ば（但愿能再见一面）——限定（句中带愿望的调子）
* 雨 さへ 降り ぬ（连雨也下起来了）——添加
* ただ 一人 のみ（只一个人）——限定
* 我 し 思ふ（是我在想）——強意

{% hint style="info" %}
だに 有两条路：跟在普通叙述后头是類推（〜さえ），而句中带着愿望・命令・意志的调子时，多半走限定（せめて〜だけでも）。分辨的线索不在助词身上，在整句的口气里。
{% endhint %}

{% hint style="info" %}
哪些词算副助词，各家出入不小：有的把「は」「も」「こそ」「さへ」「しか」一并列作副助词。本页从通行分法，只收表上这几个。
{% endhint %}
