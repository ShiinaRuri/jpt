# 格助词

接在**体言・準体言**后头，指出它与下文之间是什么关系——这一类就是格助词。

这里的「格」，指词与词之间的关系，共四样：

|   格   |    管的是   |
| :---: | :------: |
|   主格  |   谁在作主语  |
| 連体修飾格 |  修饰下面的体言 |
| 連用修飾格 |  修饰下面的用言 |
|   同格  | 与另一项同级并列 |

***

### が・の

{% hint style="info" %}
五样用法：主格・連体修飾格・同格・準体法（顶替体言）・連用修飾格（比喩）。和歌与会话文里，以連体形收尾的句子若主格用「が・の」，多半是余情表现（〜が〜ことよ 那种口气）。
{% endhint %}

* 我が 庵（我的草庵）——連体修飾格
* 峰の 雪（峰上的雪）——連体修飾格
* 花の 散る を 見る（看着花散）——主格（連体節之中）

### を

{% hint style="info" %}
表动作的对象・起点・经过的场所或时间；另有「音を泣く」（哭出声）、「寝を寝」（睡觉）这类惯用句。它算不算間投助詞，底本记了一说。
{% endhint %}

* 文 を 読む（读文章）——动作的对象
* 空 を 飛ぶ（飞过天空）——经过的场所
* 音 を 泣く（放声哭）——惯用句

### に

{% hint style="info" %}
用法最繁：场所・时间・归着点・对象・变化的结果・目的・原因理由・被动与使役的对象・比较的基准・添加・资格状态・手段方法。表目的时接在活用语的連用形后；「動詞の連用形＋に＋動詞」是一种加强语气的句形（例：冷えに冷え入りて）。另有一法：把贵人所在的场所说出来，以此婉曲地示敬。
{% endhint %}

* 京 に 住む（住在京城）——场所
* 花 に なる（变成花）——变化的结果
* 冷え に 冷え入りて（冷上加冷）——加强语气的句形

### へ

{% hint style="info" %}
表方向。
{% endhint %}

* 東 へ 行く（往东去）

### と

{% hint style="info" %}
表共同动作的对方・变化的结果・比较的基准・比喩・引用・并列；偶尔表强意。后接接续助词「て」的「とて」，译作「〜と言って・〜と思って」；把「とて」看作独立的格助词，也是一说。
{% endhint %}

* 友 と 語る（与友交谈）——共同的对方
* 生き と し 生ける もの（一切有生之物）——强意
* 問ふ とて（说着要问）——「とて」

### より

{% hint style="info" %}
表动作的起点・经过的场所・比较的基准・手段方法・即座。上代另有同义的「ゆ・ゆり・よ」；下接否定时也可表限定。
{% endhint %}

* 京 より 発つ（从京城出发）——起点
* 花 より 他 に 知る 人 も なし（除花之外再无相知）——伴否定表限定

### から

{% hint style="info" %}
表动作的起点。平安时代以前多用「より」，室町以后「から」占了上风，一直沿到今天。
{% endhint %}

* 山 から 出づ（从山里出来）

### にて

{% hint style="info" %}
表场所・时间・手段与材料・原因理由・资格状态。
{% endhint %}

* 舟 にて 行く（乘船而去）——手段
* 都 にて 見る（在京城见）——场所

### して

{% hint style="info" %}
表手段方法・共同动作的对方与人数・使役的对象。
{% endhint %}

* 筆 して 書く（用笔写）——手段
* 三人 して 行く（三人同去）——人数

***

### 附注：它和接续助词的分界

接续助词接的是活用语，把上面的文节往下接；格助词接的是体言・準体言，指出它与下文的关系。分界正在所接的那个词上。
