# 終助詞

附在各种词后头，落在句末，替整句添一口气——这一类就是终助词。文语里最热闹的是**愿望**与**禁止**两族。

### 愿望

|    終助詞    |   接续   |       意味      |
| :-------: | :----: | :-----------: |
|     ばや    |   未然形  |   自己的愿望（〜たい）  |
|     なむ    |   未然形  | 向他人的愿望（〜てほしい） |
| てしがな・にしがな |   連用形  |     〜たいものだ    |
|    もがな    |   种种词  |    〜であってほしい   |
|     がな    | 体言・連用形 |    〜があったらなあ   |

* 花 見 ばや（想赏花）——自己的愿望
* 人 に 見 せ なむ（想给人看）——向他人之愿
* 世の中 に もがな（世上若也有，该多好）

### 禁止

|  終助詞 |   接续   |    意味   |
| :--: | :----: | :-----: |
|   な  |   終止形  | 〜してくれるな |
|   そ  |   連用形  |   〜するな  |
| な……そ | 中间夹連用形 | 〜しないでくれ |

{% hint style="info" %}
禁止句里的「な」与「そ」是一对：中间夹上动词的連用形用（な 見 そ ＝ 别看见），这里头的「な」在词性上归副詞，「そ」才是終助詞。光看字形，很容易把两者当成一个字。
{% endhint %}

### 疑问・咏叹・强意

| 終助詞 |   意味  |
| :-: | :---: |
|  か  | 疑问・反语 |
|  かな | 咏叹・疑问 |
|  は  | 咏叹・提示 |
|  よ  | 咏叹・呼告 |
|  かし |   强意  |

* いか に せ む か（该怎么办呢）——疑问
* あはれ、花 かな（啊，花啊）——咏叹

{% hint style="success" %}
接在句末的终助词，与係助詞 拉起结び 的活计不同：前者只是添口气，后者要动句末的活用形。一个添味，一个改形——「か」两处都能站，靠位置分辨。
{% endhint %}
