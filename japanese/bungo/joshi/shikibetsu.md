# 识别对照表

助词里最难缠的不是背不完，是一个字挂着几副面孔。这张表把章里反复撞见的几位聚在一处，只写分辨的线索。

|  字  |      身分     |            分辨线索            |
| :-: | :---------: | :------------------------: |
|  を  |     格助詞     | 接体言・準体言，表动作的对象・起点・经过的场所或时间 |
|  を  |     接続助詞    |    接连体形，表逆接・順接的確定条件或単純接続   |
|  を  |     間投助詞    |    附在文节之间或句末，只调理语调，不动句末    |
|  に  |     格助詞     |   接体言・準体言，表场所・归着点・变化的结果等等  |
|  に  |     接続助詞    |       接连体形，与「を」走同一条路       |
|  や  |     係助詞     |     拉起结び，句末转連体形，带疑问・反语     |
|  や  |     間投助詞    |      附在词后调语调，句末的活用形不动      |
|  や  |    終助詞（说）   |       句末的「や」归終助詞，也是一说      |
|  か  |     係助詞     |         拉起结び，句末转連体形        |
|  か  |     終助詞     |     落在句末，添疑问・咏叹，不改句末形态     |
|  な  |     終助詞     |          接終止形，表禁止          |
|  な  | 副詞（な……そ 之中） |    中间夹着动词連用形用时，这个「な」算副詞    |
|  が  |     格助詞     |    接体言・準体言，表主格・連体修飾格・同格等   |
|  が  |     接続助詞    |        接连体形，平安末期才登场        |
|  し  |     副助詞     |           附在词后表强意          |

**认它，只问三件事**

1. 看它接的是什么——体言・準体言 归格助詞，活用语 归接続助詞；什么词都能接的，多半在添加意味那一层。
2. 看它落在哪里——文节之间或句末、只为调语调的，是間投助詞。
3. 看句末动不动——句末活用形跟着变，背后是係助詞；形态不动的，是終助詞在添口气。

{% hint style="info" %}
本表只聚各页已收的条目。凡有异说的（句末「や」的归属、な……そ 里「な」的词性），表里照原样标出，不做裁断。
{% endhint %}
