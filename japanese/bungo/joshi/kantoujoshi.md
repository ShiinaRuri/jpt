# 間投助詞

附在文中或句末，把语调整一整——这一类就是間投助詞。它不动句意，也不指名格，只把口气拉长些、柔些，有点像现代语里「ね」「さ」那点味道。文语里出场的主要是两个：**や** 与 **を**。

* 神 や、我 が 大君 は（神啊，我的大君）——句中，呼告
* 天 の 原 や（天上那一片）——句中，调理语调
* 花 を、いと をかし（那花呀，真有意思）——句末，余情

{% hint style="info" %}
「や」「を」都还有别的身份：や 兼作係助詞（疑问・反语），を 兼作格助詞（动作的对象）。分辨就看位置与活计——附在文节之间、句末，只为调理语调，才归間投助詞；拉起句末变形的是係助詞；接在体言后头指出关系的是格助詞。分清这一处，「を」的几个身分便不会打架。
{% endhint %}

{% hint style="success" %}
句末的「や」算不算終助詞，各家说法不一，本页从「附在词后调理语调」这一层收它；另，接续助词「を」「に」与本类同名，看接的是活用语还是各种词即可分开。
{% endhint %}
