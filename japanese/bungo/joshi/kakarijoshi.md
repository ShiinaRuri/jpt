# 係助詞

附在各种词后头，给下文的说法定下一种规矩——这一类就是係助词。它最出名的活计是**係り結び**：句中一出现它，句末的活用形就得跟着变。

| 係助詞 |   意味  |  結び |
| :-: | :---: | :-: |
|  ぞ  |   強意  | 連体形 |
|  なむ |   強意  | 連体形 |
|  や  | 疑問・反語 | 連体形 |
|  か  | 疑問・反語 | 連体形 |
|  こそ |   強意  | 已然形 |

底本留下的五个例句，正把这五样摆齐了：

* 花 こそ 摘み しか。（花，我是摘了的）——こそ 结已然形
* 花 ぞ 摘み し。（花，是摘了的）——ぞ 结連体形
* 花 なむ 摘み し——なむ 结連体形
* 花 や 摘み し——や 结連体形（疑問・反語）
* いつ か 花 摘み し——か 结連体形（疑問・反語）

{% hint style="success" %}
結び管的是句末的姿态，不是句意。「ぞ・なむ・こそ」添的是强调，「や・か」带的是疑问与反语。一句里遇上两个係助詞，按通行说法，靠后的那个统辖結び。
{% endhint %}

{% hint style="info" %}
「は」「も」也归係助詞，它们不拉起係り結び，只把上文的词拎出来当下文的话题或并列（「花は」「花も」）。底本未展开这一层，先记在此处。
{% endhint %}
