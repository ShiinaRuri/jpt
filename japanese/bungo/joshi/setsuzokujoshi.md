# 接续助词

接在**活用语**后头，把上面的文节往下接——这一类就是接续助词。它接的是连文节，与只接体言的格助词正相对。

接法先分几层，再往下落词：

|  接法  |      说的是什么      |
| :--: | :-------------: |
| 単純接続 |   顺着次序接上去，不带条件  |
| 条件接続 |    上文节是下文节的前提   |
|  順接  |   条件顺着来，后件应声而起  |
|  逆接  | 条件逆着来，后件不照上文的势走 |
| 仮定条件 |     拿未然之事当假定    |
| 確定条件 |     拿已然之事当前提    |

{% hint style="info" %}
底本里「順接」「逆接」的旧名叫「順態接続」「逆態接続」，略称才是我们现在用的这两个。名不同，指的是一件事。
{% endhint %}

***

### ば

{% hint style="info" %}
接未然形，表順接仮定条件；接已然形，则表順接確定条件——其中又分原因理由、偶然条件、恒常条件几样。
{% endhint %}

* 花 咲か ば 見 に 行かむ（花若开，便去看）——先接未然形，順接仮定
* 風 吹け ば 波 立つ（风一吹，浪就起）——接已然形，順接確定（恒常）

### と・とも

{% hint style="info" %}
接終止形，表逆接仮定条件。只有「とも」接形容词、或接打消的「ず」时，接的是連用形。
{% endhint %}

* 誰 か 問ふ とも、答へ じ（纵有人问，也不答）——逆接仮定
* 遅く とも 行かむ（就算晚，也去）——形容詞連用形接续

### ど・ども

{% hint style="info" %}
接已然形，表逆接仮定条件，也表逆接的恒常条件。
{% endhint %}

* 花 咲け ども、人 来 ず（花虽开了，人却不来）

### を・に

{% hint style="info" %}
接連体形，表逆接確定条件、順接確定条件与単純接続。
{% endhint %}

* 思ふ に、これ 三 度 の 事 なり（想来，这是第三回了）——単純接続
* 山 に 分け入る を、人 に 逢ふ（穿入山中，却遇见了人）——逆接確定

### が

{% hint style="info" %}
接連体形，表順接確定条件与単純接続。它露面很晚，到平安末期才登场。
{% endhint %}

* そこ に 立つ が、我 が 子 に は あら ず（站在那里的，却不是我那孩子）——単純接続

### て・して

{% hint style="info" %}
接連用形，表単純接続；随上下文，也能表順接仮定条件、順接確定条件、逆接確定条件。
{% endhint %}

* 花 咲き て、鳥 鳴く（花开，鸟鸣）——単純接続

### で

{% hint style="info" %}
打消的「ず」的連用形接上「て」，缩成「ずて」，再缩成「で」。接未然形，表打消的単純接続，叫打消接続。
{% endhint %}

* 知ら で 行く（不知而行）——打消接続

### つつ

{% hint style="info" %}
接動詞・助動詞的連用形，表反复与继续，也表两个动作并行。和歌里以「つつ」收尾的写法叫「つつ止め」，用来留余情、发咏叹。
{% endhint %}

* 波 打ち つつ（浪拍不止）——反复与继续
* 花 見 つつ 酒 飲む（边赏花边饮酒）——并行

### ながら

{% hint style="info" %}
接连用形或形容词词干，表逆接確定条件、两个动作并行、以及状态；偶尔接名词・副词，表「〜のままで」「〜は全部」。
{% endhint %}

* 知り ながら 言は ず（明知却不说）——逆接確定
* 三人 ながら 行く（三个人一起去）——「〜は全部」

### ものの・ものを・ものから・ものゆゑ

{% hint style="info" %}
这一族都接連体形，表逆接確定条件。例外有三：「ものから」「ものゆゑ」也能表順接確定条件；句末的「ものを」表咏叹，把它认作終助詞也是一说。
{% endhint %}

* 待ち し ものの、遂に 来 ず（等了许久，终于没来）——逆接確定
* 来 まし ものを（要是他来了就好了）——句末咏叹

***

### 附注：它接的是什么

格助词接体言，接续助词接活用语——分界正在所接的那个词上。另有两处要留神：接续种类不是词自身的属性，同一个词换个接续、换个上下文，順接与逆接就会改口；又，底本以「順態接続」「逆態接続」为正名，本页从略称写作「順接」「逆接」。
