# 助词

与用言相对，助词与助动词同属**附属语**：不能单独成句，只能附在别的词后头。两者之间有一条分界——助动词有活用，助词没有。

照资料的框架，助词先分两层，再落成六类：

|    層    |   類  | 附在什么后面 |    干的是什么活    |
| :-----: | :--: | :----: | :----------: |
| 関係を示唆する |  格助詞 | 体言・準体言 | 指出它与下文的关系（格） |
| 関係を示唆する | 接続助詞 |   活用語  |   把上面的文节往下接  |
| 意味を添加する |  副助詞 |   各种词  |    添上种种意味    |
| 意味を添加する |  係助詞 |   各种词  |   给下文指定一种说法  |
| 意味を添加する |  終助詞 |   各种词  |   添上意味，落在句末  |
| 意味を添加する | 間投助詞 |   各种词  |    把语调调理齐整   |
