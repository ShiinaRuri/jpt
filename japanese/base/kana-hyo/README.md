但请记住，假名是日语的入门基础。接下来的章节，能够熟练的使用假名是学习日语语法的先决条件。

开拗音：

> &#x20;    [上古日语](https://zh.wikipedia.org/wiki/%E4%B8%8A%E5%8F%A4%E6%97%A5%E8%AA%9E)没有“拗音”。“拗音”的出现，是因为古代[日本人](https://zh.wikipedia.org/wiki/%E6%97%A5%E6%9C%AC%E4%BA%BA)在引入汉语借词时，需要新的音以扩充[日语音系](https://zh.wikipedia.org/wiki/%E6%97%A5%E8%AA%9E%E9%9F%B3%E7%B3%BB)转写来自[中古汉语](https://zh.wikipedia.org/wiki/%E4%B8%AD%E5%8F%A4%E6%B1%89%E8%AF%AD)的发音。因此，大部分的拗音词汇出现在[汉语词汇](https://zh.wikipedia.org/wiki/%E6%B1%89%E8%AF%AD%E8%AF%8D%E6%B1%87)，亦或[和制汉语](https://zh.wikipedia.org/wiki/%E5%92%8C%E5%88%B6%E6%B1%89%E8%AF%AD)词汇。
>
