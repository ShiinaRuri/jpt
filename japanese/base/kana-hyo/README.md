{% hint style="info" %}
**ゐ|ヰ・ゑ|ヱ** 是 ワ行 的 イ段・エ段。它们原本读作 /wi/・/we/，中世以后分别与「い」「え」合流，现代语里已不再书写；但文语、旧假名遣与旧文献里仍在用，遇到时按 い・え 读即可。\
（ワ行 的 ウ段 与 ア行 的「う|ウ」同形，故不另列。）
{% endhint %}

## 书写上的三条规则

促音、長音、撥音——这三样都不占五十音的格子，却跟每个词打交道，所以单立一层。

### 一、促音「っ」「ッ」

小的「っ」不发音，只把拍子空出一拍。

* 学校 → がっこう
* 切手 → きって
* 片假名写「ッ」：ベッド、サッカー

促音只出现在词中，不会出现在词头。

### 二、長音

平假名的长音，随前一个假名所在的段改变写法：

|  段  |     写法    |     例     |
| :-: | :-------: | :-------: |
|  ア段 |     ＋あ    |   おかあさん   |
|  イ段 |     ＋い    |   おにいさん   |
|  ウ段 |     ＋う    |    くうき    |
|  エ段 | ＋い（偶作 ＋え） | えいが／おねえさん |
|  オ段 | ＋う（偶作 ＋お） | おとうさん／とおい |

片假名一律用长音符「ー」：コーヒー、タクシー。

文语与旧假名遣里不写长音符，长音多以「う」「ふ」「ゐ」等历史写法保存——例如「けふ」读作 きょう。读旧文时要照历史假名遣读，不能照字面拼。

### 三、撥音「ん」「ン」

「ん」是唯一单独占格、又能独立成一拍的音；它不能单独成词，一定跟在别的假名后面。

* しんぶん：受后面「ぶ」影响，「ん」实际读 m
* かんがえる：受后面「が」影响，读 ŋ
* 片假名写「ン」：パン、ペン

除少数口语叹词（单说一个「ん」表示应答）之外，「ん」不在词头出现。
