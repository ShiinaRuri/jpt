# 基础用语

### 推荐初学者先完成下面基础用语的背诵，在完成背诵后，初学者可以对日语有一个初步的记忆。

{% tabs %}
{% tab title="全假名（建议初学者阅读）" %}
ありがとうございます。谢谢您。

いただきます。我开动了。

いってきます。我出去了。

いってっらしゃい。一路走好。

いらっしゃいませ。欢迎光临。

おかえりなさい。您回来了。

おかげさまで。托您的福。

おげんきで。保持开心。

おだいじに。多保重。

おねがいします。拜托您了。

おはようございます。早上好。

おやすみ。晚安

かしこまりました。我明白了。

ごちそうさまでした。谢谢招待。

こちらこそ。哪里，我才是....

ごめんなさい。对不起

こんにちは。您好。

こんばんは。晚上好。

さようなら。再见。

ただいま。我回来了

では、また。再见。

どういたしまして。不用谢。

どうぞよろしくおねがいします。请多关照。

はじめまして。初次见面。
