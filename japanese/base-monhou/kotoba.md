# 「语言」单位

### 「语言」 <a href="#goen" id="goen"></a>

日语的句子可以被分割成好几&#x4E2A;**「单位」**。

在较长的句子中，如果不能明白句子的含义，可以将句子分割为各个单独内容以便于理解。

日语中包含以下单位：

{% tabs %}
{% tab title="「语言」単位" %}
文章：包含着一个或以上的「文」的单位。

段落：使「文章」分成几段，便于解读。

文：一般指一个句子，或者一行以「。」结尾的单位。

文节：将「文」中不同意义的词语切开。

单语：即单词，「语言」中最小的单位。
{% endtab %}
{% endtabs %}

### 「句読点」 <a href="#kutouten" id="kutouten"></a>

「。」&#x662F;_&#x53E5;点_(くてん)，「、」&#x662F;_&#x8AAD;点_(とうてん)。

这两个合起来叫&#x505A;_&#x53E5;読点_(くとうてん)。

### 「文节」的分割方法 <a href="#bunsetsu-kirihiki-kata" id="bunsetsu-kirihiki-kata"></a>

一般的，文节用「よ」，「ね」等不常用的假名来将「文节」从「文」中分隔开。

需要分割的成分是：「名詞」、「形容詞」、「動詞」等，或者「自立語」之前。
