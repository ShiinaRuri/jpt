# 「文节」的种类

首先，「文节」以在句子中的成分被分为主語・述語・修飾語・接続語・独立語五种。

{% hint style="info" %}
在本节内容，例句都会以【椎名るり】作为第三人称的主语或者宾语。
{% endhint %}

## 「主語」

「主語[^1]」在「文」中，是提示某人或某物的「文节」。名词以「は」、「が」、「も」等助词提示「主语」的情况最多。

> **私**は男だ。\
> **我**是男人。
>
> 彼女の**名前**は椎名るりだ。\
> 她的名字是椎名るり。
>
> あの高い**ビル**は私住んでいる所だ。\
> 那一栋高的**建筑**是我住的地方。

## 「述語」 <a href="#jyukugo" id="jyukugo"></a>

&#x20; 「述語[^2]」在「文」中，表达【怎么做】，【怎么样】，【状态如何】等意义的「文節」。

&#x20;「述語」多数在句尾使用，用于说明主语。

{% hint style="info" %}
在中文，与此对应的语法是【宾语】。
{% endhint %}

> 椎名さんは**歩く**。\
> 椎名在**走路**。\
> \
> 椎名さんはとても**楽しい**。\
> 椎名非常的**开心**。

## 「修飾語」 <a href="#kyushikigo" id="kyushikigo"></a>

&#x20; 「修飾語[^3]」用于详细地说明或修饰其他文节。被「修飾語」说明的文节叫做「被修飾語」。

{% hint style="info" %}
在中文，与此对应的语法是【定语或状语】。\
修饰【动词】的是【状语】，修饰【名词】的是【定语】。
{% endhint %}

> 今日、私は**綺麗な**眼鏡を掛かった。\
> 今天，我带了**漂亮的**眼镜。
>
> これは**非常に**珍しいものであり。\
> 这是**非常**罕见的东西。

## 「接続語」 <a href="#setsusokugo" id="setsusokugo"></a>

「[**接続語**](#user-content-fn-4)[^4]」是连接或关系两个或以上「文」或「文节」的文节。「文」的语义一大部分的关系取决于接续语。

{% hint style="info" %}
在中文，与此对应的语法是【连词】。
{% endhint %}

> あいつは女の子だ。**しかし**、男装がいつも着る。\
> 那家伙是女孩子。**但是**，总是穿着男装。
>
> あいつは女の子だ。**だから**、女装がいつも着る。\
> 那家伙是女孩子。**所以**，总是穿着女装。

## 「独立語」 <a href="#dokuritugo" id="dokuritugo"></a>

「独立語[^5]」是与其他「文節」没有任何关系的独立文节。\
独立语在句子中算作独立成分，与其他内容没有任何关系。

{% hint style="info" %}
在中文，与此对应的语法是【语气词】。
{% endhint %}

> **ほら**、あそこには犬がいる。\
> **看啊**，那边有一只狗。
>
> **今日は**、良い天気だね。\
> **你好**，今天天气真不错呢。

「文節[^6]」存在以上五种元素。

{% tabs %}
{% tab title="「文節」的作用" %}
主語：赋予某物、某人的主要元素\
述語：赋予怎么做、怎么样、变得怎样的元素\
修飾語：详细说明或解释其他文节内容的元素\
接続語：联系前后文的元素\
独立語：与其他文节无关联的元素
{% endtab %}
